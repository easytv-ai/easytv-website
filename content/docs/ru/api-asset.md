Нужна [авторизация](/docs/api-auth). Тип определяется по MIME: `image` / `video` / `audio` / `text` / `other`. Максимальный размер файла по умолчанию — 200 МБ (`UPLOAD_MAX_MB`). При использовании Qiniu браузер загружает файл напрямую, а затем регистрирует его через `POST /user/asset/import`.
