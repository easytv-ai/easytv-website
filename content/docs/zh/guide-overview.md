「使用指南」按产品面拆页。创作从 [创作台](/docs/studio) 进，运营从 [运营后台](/docs/admin) 进。

![创作台](/images/docs/studio.png)

## 创作者

| 页 | 讲什么 |
| --- | --- |
| [创作台](/docs/studio) | easytv-web 路由、七语种、怎么指到你的 API |
| [自由画布](/docs/canvas) | 节点、乐观锁、版本、只读分享 |
| [一句话成片](/docs/create) | 输入 → 策划案 → 分层生成 → 合成 |
| [3D 导演台](/docs/director) | 站位、机位、写回画布 |
| [媒体工具](/docs/media) | 浏览器 ffmpeg 与服务端后处理 |
| [社区与技能](/docs/community) | 作品流、评论、Skill 分成 |
| [登录与团队](/docs/team) | 邮箱 / 短信 / 微信，团队空间 |

## 运营与渠道

| 页 | 讲什么 |
| --- | --- |
| [计费与支付](/docs/billing) | 积分、会员、微信 / 支付宝 |
| [运营后台](/docs/admin) | 用户、审核、定价、网关 |
| [渠道后台](/docs/partner) | 返佣、提现、物料 |
| [对接网关](/docs/gateway) | 拉模型、导入定价 |

接口怎么对页面，见 [API 参考](/docs/api) 里的页面对照表。
