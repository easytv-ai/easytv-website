---
title: Сравнение
description: EasyTV на своём сервере и коммерческие SaaS для коротких сериалов. Столбец SaaS составлен по открытым материалам.
---

EasyTV оставляет производственный конвейер на ваших машинах. Запросы к моделям по-прежнему идут через ваш шлюз.

| | EasyTV | Коммерческие SaaS (LibTV и др.) |
| --- | --- | --- |
| Исходный код и размещение | AGPL-3.0, ваши серверы | Закрытый код, хостинг у поставщика |
| Модели | Любой шлюз, совместимый с OpenAI | Список и цены поставщика |
| Биллинг | Кредиты, тарифы и акции задаёте вы | Цены поставщика |
| Платежи | WeChat / Alipay, счета, выплаты | Деньги принимает поставщик |
| Данные | Ваше объектное хранилище | Хранилище поставщика |
| Команды | Пространство, роли и согласования встроены | Обычно платный тариф |
| Языки | Семь встроенных | По-разному |
| Доработка | Открытый контракт, можно расширять | Недоступна |

Ограничения лицензии описаны на странице [Лицензия](/docs/license). Части `easytv-api` основаны на сторонних проектах под AGPL-3.0, поэтому сам по себе он не может быть закрытым.
