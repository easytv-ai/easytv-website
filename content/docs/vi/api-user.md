`/user/*` cần [xác thực](/docs/api-auth). `quota` trong `GET /user/self` là trường cũ — tính phí dùng [ví](/docs/api-wallet).

Dự án, canvas và tác vụ nằm trong các nhóm riêng; trang này chỉ nói về bản thân tài khoản.
