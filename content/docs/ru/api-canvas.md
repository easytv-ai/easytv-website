---
title: Холст
description: Непрозрачный graph, оптимистичная блокировка version, история, общий доступ только для чтения и чат.
---

Нужна [авторизация](/docs/api-auth). Путь в студии — `/canvas?id=`. Бэкенд **не** разбирает семантику узлов. Не более **2 МБ на холст**. Не сохраняйте base64 снимков камеры в `data.scene` узла режиссёрской сцены.

При сохранении нужно передавать текущую `version`, иначе вернётся «画布已在其他地方修改，请刷新». Не более 50 версий. Путь общего доступа — `/share/<token>`.
