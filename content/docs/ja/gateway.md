---
title: ゲートウェイ連携
description: OpenAI 互換ゲートウェイを EasyTV に接続し、モデルを取得してクレジット価格を取り込みます。
---

EasyTV は OpenAI 互換のインターフェースを通じてモデルを呼び出します：`/v1/chat`、`/v1/images`、`/v1/videos`（およびゲートウェイが提供する音声機能）。**生成の前に、まずゲートウェイが必要です。**

ゲートウェイのアドレスと Key は、管理コンソールの **システム → ゲートウェイ** で入力します。変更はすぐに反映されます。

![管理コンソールのシステムとゲートウェイ](/images/docs/admin.svg)

## 初回の接続

1. 稼働中の OpenAI 互換ゲートウェイのトークンを用意します。使いたいテキスト / 画像 / 動画モデルを呼び出せるトークンである必要があります。
2. `admin` で管理コンソールにログイン → **システム → ゲートウェイ**。
3. ゲートウェイの Base URL と Key を入力して保存します。
4. モデル一覧を取得し、使うモデルの **価格を取り込み** ます。
5. **モデル価格** で、秒 / 枚 / 回数あたりのクレジット単価を確認します。スタジオの費用見積もりはここを参照します。

対応する setting のキー：`EasyAPIGatewayBaseUrl`、`EasyAPIGatewayKey`、`EasyAPIGatewayEnabled`。単価は `model_price` テーブルにあります。

呼び出しのエンドポイントと価格のエンドポイントが同じドメインにない場合（例：呼び出しは `api.xxx.com`、価格は `token.xxx.com`）は、`EasyAPIGatewayPricingBaseUrl` も設定します。ゲートウェイ残高の照会には、管理画面の「システムアクセストークン」`EasyAPIGatewayAccessToken` が必要です（呼び出し用の sk トークンでは実際の残高を確認できません）。残高が `GatewayBalanceAlertUSD`（既定 20 米ドル）を下回ると、管理者にサイト内通知が送られます。

推奨クレジット：

```
gateway USD cost × FX (7.3) × markup (3) × credits-per-yuan (20)
```

従量課金のモデルは、想定 token 使用量をもとに回数 / 枚 / 秒に換算されます。これらの係数はすべてゲートウェイ設定で変更できます。取り込み後も **モデル価格** で確認してください。特に動画の秒単価と、トーキングヘッドに必要な `native_audio` の能力タグに注意します。

## ゲートウェイが実際に受けるパス

EasyTV はベンダーの SDK に直接接続せず、すべて `service/providers/easyapi.go` を通します：

| 種類 | ゲートウェイのパス |
| --- | --- |
| テキスト | `POST /v1/chat/completions`（ビジョン用に画像を最大 4 枚まで添付可能） |
| 画像 | `POST /v1/images/generations` |
| 音声 | `POST /v1/audio/speech` |
| 動画 | `POST /v1/videos` のあと `GET /v1/videos/{job_id}` をポーリング |

素材には `input_references[{type,url,role}]` を使います。画像から動画を生成する際の URL は、ゲートウェイが GET できる公開アドレスでなければなりません。[オブジェクトストレージ](/docs/storage) を参照してください。

429 / 503 は最大 2 回リトライします（`Retry-After` に従います）。502 / 504 は上流ですでにタスクが作成されている可能性があるため、再送しません。マッピング済みのエラーはクリエイター向けの中国語の一文に変換され、原文は SysLog に記録されます。

## モデルの供給元

EasyTV はベンダーの SDK を内蔵していません。Kling、Jimeng、Seedance、Hailuo、Sora、GPT、Qwen、MiniMax などは、ゲートウェイが上記の OpenAI 形式のルートに変換できればそれで十分です。モデルの切り替え = ゲートウェイのチャネルの切り替えであり、EasyTV のコードを変える必要はありません。

## つまずきやすい点

- ゲートウェイは 200 を返すのにスタジオではずっとキュー待ちになる：API ログで上流のエラーを確認し、そのモデルの価格が取り込まれているかも確認します。
- チャットモデルしか設定していない：画像 / 動画ノードは失敗します。ゲートウェイが対応するルートも公開している必要があります。
- Base URL に `/v1` を余分に書いた：管理コンソールの案内どおりに入力し、ゲートウェイのドキュメントにあるパスと二重にならないようにします。
