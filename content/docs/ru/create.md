Путь `/create`. Шаги мастера: ввод → план → генерация по слоям → монтаж → готово. Контракт: API.md §8.2.

![Фильм по одной фразе](/images/docs/create.png)

Анонимные посетители видят шаг 1; для генерации плана нужен вход. Состояние мастера хранится в sessionStorage по id сценария; обновление страницы или `?screenplay=` продолжают работу.

## Процесс

### 1. Ввод

Один промпт (около 8000 символов), длительность 15 / 30 / 60 секунд, необязательный стиль. `POST /user/screenplay` синхронно вызывает текстовую модель и списывает оплату один раз по цене текстовой единицы.

Текстовая модель по умолчанию: выбор в этой сессии → последняя запомненная → `ComposePlanModel` в разделе **Рост** админ-панели → первая текстовая модель с ценой.

### 2. План

Примерная структура:

```json
{
  "title": "",
  "style": "cinematic, cool grade",
  "aspect": "16:9",
  "characters": [{ "key": "c1", "name": "", "look": "wardrobe" }],
  "scenes": [{ "key": "s1", "name": "", "look": "set" }],
  "shots": [{ "no": 1, "scene": "s1", "characters": ["c1"], "prompt": "frame", "motion": "camera", "line": "dialogue", "seconds": 5 }]
}
```

Ограничения: ≤ 12 кадров, ≤ 4 персонажей, ≤ 4 сцен. Сохранение — `PUT /user/screenplay/:id`.

`POST /user/screenplay/:id/estimate` рассчитывает кредиты по слоям для выбранных моделей изображений / видео / аудио.

### 3. Сборка холста и генерация

`POST /user/screenplay/:id/build` создаёт холст (и проект, если нужно):

- текстовый узел: краткое изложение плана
- по одному изображению на персонажа (`sp.layer=character`)
- на каждый кадр: изображение → видео → озвучка, если есть реплика

Затем запускайте слой за слоем или доверьте пакетный запуск мастеру. Значения по умолчанию берутся из настроек `ComposeImageModel` / `ComposeVideoModel` / `ComposeAudioModel` (админ-панель, **Рост → монтаж**). Если один из маршрутов шлюза недоступен, измените эти три ключа — код менять не нужно.

### 4. Монтаж

`POST /user/canvas/:id/compose` берёт успешно сгенерированные видеоузлы (по координате x или `clip_order`), приводит их через ffmpeg к 1280×720 / 30 кадров/с, вшивает SRT и подмешивает фоновую музыку на уровне −14 дБ. Бесплатные пользователи получают водяной знак `EasyTV.ai` (включён `ComposeWatermarkEnabled`, и пользователь не подписчик).

Монтаж **не расходует кредиты**. У пользователя может быть не более 3 заданий монтажа в очереди / в работе; общая очередь ограничена 20. Задания старше 10 минут завершаются ошибкой. Опрашивайте `GET /user/compose/:id`.

Фильм сохраняется как ассет (`source=compose`), и его можно опубликовать на `/watch/:id`.

## Типичные сбои

- Ошибка разбора плана: API один раз повторяет запрос к текстовой модели
- 502 при генерации видео по изображению: некоторые каналы шлюза работают для текста в видео, но не для изображения в видео. Укажите в `ComposeVideoModel` модель, которую вы проверили
- 429 / 503 от шлюза: бэкенд повторяет запрос дважды (учитывает `Retry-After`). Когда повторы исчерпаны, возвращается «模型当前排队较多»
