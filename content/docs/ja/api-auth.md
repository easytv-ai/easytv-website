スタジオ、管理コンソール、パートナーコンソールは同じログインを共有します。**認証に Cookie を使わないでください。** 以下の `$API` の既定値は `http://127.0.0.1:8383` です。

各エンドポイントの Header、リクエストボディ、200 レスポンスは左側のサブメニューにあります。

## リクエストヘッダー

| Header | 必要な場面 | 説明 |
| --- | --- | --- |
| `Authorization` | `/user/*`、`/admin/*` | `Bearer <access_token>` |
| `EasyTV-User` | 同上 | 現在のユーザー id。token のユーザーと一致している必要があります |
| `EasyTV-Team` | 任意 | チームスペースの id。省略 / `0` は個人スペース |
| `Content-Type` | JSON リクエストボディ | `application/json` |
| `Accept-Language` | モデル詳細など | そのままゲートウェイに転送され、文言の言語に使われます |

`/admin/*` ではさらに `role ≥ 10` が必要です。システム設定の変更、返金、クレジット調整などには `role ≥ 100`（RootAuth）が必要です。チームスペースに切り替えるときは `EasyTV-Team` を追加します。チームスペースでの生成はチームのクレジットプールを消費し、個人スペースでは常に自分のウォレットを消費します。

## レスポンス形式

HTTP ステータスは **常に 200** です。JSON の `success` で判定します。権限がない場合もリソースが存在しない場合も `success: false, message: "资源不存在"` を返し、存在の列挙を防ぎます。一部のエンドポイントは `code` も返します（例：パートナーコンソールの `not_applied` / `not_approved`）。

## よくあるエラー

| message | 意味 |
| --- | --- |
| `无效的参数` | JSON を解析できない、または必須項目が空 |
| `用户名或密码错误` | ログイン失敗。アカウントが存在するかどうかは区別しません |
| `资源不存在` | 権限がない、または実際に存在しない |
| `权限不足` | 通常の管理者が RootAuth のエンドポイントを呼び出した |
| `积分不足，还需 N 积分` | タスク作成時の事前引き落としに失敗 |
| `模型未定价` / `模型暂未接入` | `model` が `model_price` の有効な一覧にない |
