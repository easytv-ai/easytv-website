---
title: ほかの選択肢との比較
description: セルフホストの EasyTV と商用のショートドラマ SaaS の違い。商用サービスの列は各社の公開情報に基づきます。
---

EasyTV が目指すのは、ショートドラマの制作ラインをあなた自身のサーバーに置くことです。モデルは引き続きあなた自身のゲートウェイを経由します。

| | EasyTV | 商用 SaaS（LibTV など） |
| --- | --- | --- |
| ソースコードとデプロイ | AGPL-3.0。自分のサーバーにデプロイ | クローズドソース、ベンダーがホスト |
| モデルの供給元 | 任意の OpenAI 互換ゲートウェイ。ベンダーも価格も自分で選ぶ | ベンダー指定のモデルと価格 |
| 課金と価格設定 | クレジット / 会員 / 特価は自分で決める | ベンダーが決定 |
| 決済と精算 | WeChat Pay / Alipay と直接接続。請求書、アフィリエイト、出金 | ベンダーが代行回収 |
| データの所有 | 素材、キャンバス、完成映像は自分のストレージに保存 | ベンダー側に保存 |
| チームでの共同作業 | チームスペース、ロール、承認ゲート | 多くは有料のチームプラン |
| 多言語 | 7 言語を内蔵 | サービスによる |
| カスタマイズ | 契約を公開。改変も拡張も可能 | 非公開 |

ライセンスの範囲は [ライセンス](/docs/license) を参照してください。`easytv-api` には上流の AGPL-3.0 オープンソースプロジェクトから派生したモジュールが含まれるため、単独でクローズドソースの商用製品にすることはできません。
