Руководства разделены по частям продукта. Авторам стоит начать со [студии](/docs/studio), операторам — с [админ-панели](/docs/admin).

![Студия](/images/docs/studio.png)

## Авторам

| Страница | О чём |
| --- | --- |
| [Студия](/docs/studio) | маршруты easytv-web, языки, подключение к вашему API |
| [Холст](/docs/canvas) | узлы, оптимистичная блокировка, версии, общий доступ |
| [Фильм по одной фразе](/docs/create) | ввод → план → слои → монтаж |
| [Режиссёрская сцена](/docs/director) | мизансцена, камеры, запись на холст |
| [Медиаинструменты](/docs/media) | ffmpeg в браузере и постобработка на сервере |
| [Сообщество](/docs/community) | лента, комментарии, доля от навыков |
| [Вход и команды](/docs/team) | e-mail / SMS / WeChat, командное пространство |

## Операторам и партнёрам

| Страница | О чём |
| --- | --- |
| [Биллинг](/docs/billing) | кредиты, тарифы, WeChat / Alipay |
| [Админ-панель](/docs/admin) | пользователи, модерация, цены, шлюз |
| [Кабинет партнёра](/docs/partner) | вознаграждения, вывод средств, промоматериалы |
| [Шлюз](/docs/gateway) | загрузка моделей, импорт цен |

Соответствие страниц и маршрутов — в [обзоре API](/docs/api).
