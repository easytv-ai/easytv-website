---
title: Console partenaires
description: /user/partner/console/* pour easytv-partner. Même connexion que le studio ; les données sont limitées à l'appelant.
---

Il n'existe pas de compte partenaire distinct. Les partenaires se connectent avec leur compte utilisateur EasyTV. Les pseudos sont masqués ; ni mobile, ni e-mail, ni lignes de commande des clients.

Sans candidature : `success=false, code="not_applied"`. Sans approbation : `stats` / `customers` renvoient `code="not_approved"`. Le solde de commissions est exprimé en CNY, converti à partir du `quota` de l'utilisateur ; ce ne sont **pas** des crédits du studio.
