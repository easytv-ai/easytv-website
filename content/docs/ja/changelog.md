ここには、ドキュメントサイトから見える変更だけを記載します。プロダクトリポジトリはそれぞれ `CHANGELOG.md` を管理しています。

## ドキュメントサイト easytv-website

- 中国語と英語のドキュメントサイト `/docs`、`/en/docs`：はじめに、インストール、ガイド、API リファレンス、ヘルプに分割
- テーマはトップページと共通になり、ドキュメントに入ると強制的にダークになることはなくなりました
- アーキテクチャ図のラベルが API / ゲートウェイのボックスと重ならなくなりました
- pnpm、AGPL-3.0、コントリビューションとセキュリティの説明

## スタジオ easytv-web

- Docker イメージと実行時の `NUXT_PUBLIC_*`
- デュアルライセンス：AGPL-3.0 + 商用ライセンスのテンプレート
- メディアプロキシのホワイトリストを実行時設定から読み込むように変更

## バックエンド easytv-api

- 契約は引き続きリポジトリ内の `API.md` が正本です（現在は第 38 章まで）
- 生成は OpenAI 互換ゲートウェイのみを経由し、ベンダーには直接接続しません
- クレジットは `model_price` に基づいて事前引き落としされ、失敗またはキャンセル時に返金されます

未リリースの項目は、各リポジトリの `CHANGELOG.md` の `[Unreleased]` を参照してください。
