スタジオは作業場であるだけでなく、公開された完成映像のコミュニティも備えています。運営担当は管理コンソールで作品、コメント、スキルを審査します。

![探索ページの作品フィード](/images/docs/explore.png)

## 作品

クリエイターはアセットから公開します：`POST /user/work`。公開フィードは `GET /work`、詳細は `/watch/:id`（閲覧数 +1）です。作者は「制作過程」`/process/:id` を公開するかどうかを選べます。

スタジオのルート：

| パス | 説明 |
| --- | --- |
| `/explore` | フィード。おすすめを優先表示 |
| `/studio` | おすすめ |
| `/following` | フォロー中 |
| `/rank` | ランキング |
| `/author/:id` | 作者ページ |
| `/watch/:id` | 再生 |

いいね、コメント、通報にはログインが必要です。運営担当は **作品 / コミュニティ審査 / 通報** で掲載と停止を切り替え、通報を処理します。おすすめ作品とトップページのバナーは、管理コンソールで別途編成します。

## スキル

スキルは再利用できるワークフローテンプレート（プロンプト + 任意のキャンバス graph）です。

- ライブラリ `/skills`：公式スキル + 審査を通過したユーザースキル
- クリエイターは `POST /user/skill/:id/submit` で申請し、運営担当が **スキル** ページで審査します
- ほかの人があなたのスキルを使うと収益分配が記録されます。収益はクレジットに交換するか、人民元で出金できます（換算レートは `GrowthPointsPerYuan`、既定は 1 元あたり 20 クレジット）

管理コンソールでは、プロンプトライブラリ、スタイルライブラリ、キャラクターライブラリ（キャラクター三面図）も管理でき、キャンバスの参考として使えます。

## グロース

招待コード `/invite/:code`、パートナーコード `/partner/:code` または `/p/:code`、ボーナスコードは、登録時に帰属先として記録されます。ルールは管理コンソールの **システム → グロース** にあります：登録特典、チェックイン、招待リワード、アトリビューション期間。パートナー側については [パートナーコンソール](/docs/partner) を参照してください。

キャンペーンページは `/campaign` で、運営担当が **キャンペーン** で設定します。
