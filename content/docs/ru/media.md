Более двадцати пунктов панели инструментов используют общий `media_job`. Локальные действия ffmpeg бесплатны и создают настоящие ассеты; действия моделей оплачиваются через способности с заданной ценой. Контракт: глава 23 API.md.

На хосте API нужны `ffmpeg` / `ffprobe` (в `PATH` или в настройках `FFmpegPath` / `FFprobePath`). В админ-панели, **Система → Медиа**, можно скрывать кнопки и менять ограничения очереди.

## Локальные действия (бесплатно)

Без ffmpeg вся группа недоступна.

| action | Название | Источник → результат |
| --- | --- | --- |
| `crop` | Кадрирование | видео / изображение |
| `grid_split` | Нарезка сеткой | изображение → N изображений (1–25) |
| `montage` | Сборка раскадровки | N изображений → одна сетка |
| `trim` | Обрезка | видео / аудио |
| `split` | Разделение | одно на два |
| `remove_silence` | Удаление пауз | видео / аудио |
| `extract_audio` / `mute_video` / `split_av` | Звук / без звука / разделение аудио и видео | видео |
| `mix_bgm` | Добавление фоновой музыки | видео + аудиоассет |
| `extract_frame` / `extract_frames` | Кадр / раскадровка лентой | видео → изображения |
| `storyboard` | Разбор на кадры | раскадровка лентой + анализ текстовой моделью |
| `compress` | Сжатие | видео / изображение |

Ограничения по умолчанию: 3 задания в очереди / в работе на пользователя, 20 всего (настраивается в админ-панели). Ограничение частоты создания: 30 в минуту.

Нарезка сеткой **не кадрирует в браузере** — из OSS без CORS нельзя прочитать пиксели, — поэтому одно задание выдаёт N результатов.

## Действия моделей (платно)

Теги способностей хранятся в `model_price.abilities` (через запятую). При пустых тегах используется сопоставление по имени (`*upscale*`, `*subtitle*`, `*demucs*` …). Если способности нет, кнопка показывается отключённой, а не выдаёт ошибку по клику.

Распространённые теги: `upscale`, `remove_subtitle`, `vocal_separation`, `bgm_separation`, `matting`, `subject_remove` / `modify` / `replace`, `motion_capture`, `native_audio` (для «говорящей головы» показываются только видеомодели, способные произнести реплику), `video_reference` (универсальные референсы / ремикс).

Создание действия модели создаёт и задачу генерации: при нехватке кредитов, отсутствии цены у модели или превышении лимита параллельных задач запрос завершается ошибкой, и задание не создаётся.

## Монтаж в браузере

В студию также встроен FFmpeg.wasm для обрезки / разделения / склейки целиком на клиенте. Большие файлы и монтаж на таймлайне по-прежнему идут через API.
