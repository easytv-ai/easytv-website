---
title: Объектное хранилище
description: Локальный каталог upload, Aliyun OSS или Qiniu и почему для видео по изображению нужен публичный URL.
---

Загруженные файлы, результаты генерации и смонтированные фильмы должны где-то храниться. Выберите один вариант; переключаться можно на лету.

## Локальный диск

По умолчанию. Каталог `UPLOAD_DIR` (по умолчанию `./upload`), раздаётся по `GET /upload/*`.

Compose хранит его в томе `upload`. Для генерации видео по изображению шлюз должен получить исходник запросом **HTTP GET**:

- Локально: задайте в `UploadBaseUrl` адрес, доступный шлюзу, например `http://YOUR_PUBLIC_IP:8383/upload` или туннель
- Всё на одной машине: иногда работает `http://host.docker.internal:8383/upload`

Без публичного URL задания «изображение в видео» / с референсными изображениями завершаются ошибкой; для «текст в видео» это обычно неважно.

## Aliyun OSS

Переменные окружения (читаются один раз при запуске):

| Переменная | Значение |
| --- | --- |
| `OSS_BUCKET` | Если задана, включается OSS и прекращается локальная запись |
| `OSS_ENDPOINT` | например `oss-cn-hangzhou.aliyuncs.com` |
| `OSS_ACCESS_KEY_ID` / `OSS_ACCESS_KEY_SECRET` | В продакшене используйте RAM-пользователя с минимальными правами |
| `OSS_BASE_URL` | CDN или публичный хост бакета |
| `OSS_PREFIX` | Префикс объектов, по умолчанию `easytv` |
| `OSS_PUBLIC_READ` | Публичное чтение или нет |

`/upload/*` перестаёт быть основным путём. Если у бакета не настроен CORS, кадрирование / раскадровка лентой в студии не могут прочитать пиксели — добавьте хост в `NUXT_PUBLIC_MEDIA_HOSTS` и используйте серверный прокси.

## Qiniu

Настройки (админ-панель, **Система → Шлюз и хранилище**), применяются на лету:

`QiniuAccessKey` / `QiniuSecretKey` / `QiniuBucketName` / `QiniuDomain`

После этого загрузки и результаты используют публичные URL CDN, поэтому для «изображения в видео» `UploadBaseUrl` обычно не нужен. Прямая загрузка с клиента: `GET /user/qiniu/upload-token`, `GET /user/qiniu/key`.

## Что выбрать

| Ситуация | Выбор |
| --- | --- |
| Разработка на ноутбуке | Локально; добавьте `UploadBaseUrl`, когда понадобится «изображение в видео» |
| Свой сервер на одной машине | Локальный диск, `/upload/` раздаёт Nginx |
| Продакшен + CDN | OSS или Qiniu, публичное чтение или подписанные URL |
