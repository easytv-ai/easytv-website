## 登录

创作台和渠道后台共用同一套账号。

| 方式 | 接口 | 说明 |
| --- | --- | --- |
| 邮箱 + 密码 | `POST /user/login` | |
| 手机验证码 | `GET /sms/verification` + `POST /user/sms_login` | 未注册会自动建号 |
| 微信开放平台 | OAuth | 后台填回调域名；开发可关真实 SMTP / 短信，验证码打在 API 日志 |

登录响应带 `access_token`。之后每个需登录请求：

```
Authorization: Bearer <access_token>
EasyTV-User: <user_id>
```

运营后台走 `/admin/*`，还要 `role ≥ 10`。改系统设置、退款、调积分要超级管理员 `role ≥ 100`（就是首次启动那个 `admin`）。

管理员可以给某个用户签发一次性「控制台」凭证，打开创作台或渠道后台免密进入（代登排障）。

## 团队空间

创作台顶栏：**个人空间** / **团队空间**。一个人最多属于一个团队。请求头 `EasyTV-Team: <team_id>`（缺省或 0 = 个人）。

规则：

1. 个人空间永远花自己的钱包，即使你是某团队成员
2. 团队空间花 **团队 owner 的积分池**；owner 的团队版会员过期则拒绝（`team_expired`）
3. 老项目留在个人空间，作者可以把项目移进 / 移出团队
4. 角色 `admin` / `editor` / `viewer`。查看者不能用团队积分生成
5. 被移出团队时接口返回 `team_forbidden`，前端应清掉头、切回个人空间

会员计划有「创作版」单席和「团队版」多席（2–10，折扣见 `BillingPromo`）。并发路数和云存储跟套餐走。
