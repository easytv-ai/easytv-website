## 登入

創作台和通路後台共用同一套帳號。

| 方式 | 介面 | 說明 |
| --- | --- | --- |
| 信箱 + 密碼 | `POST /user/login` | |
| 手機驗證碼 | `GET /sms/verification` + `POST /user/sms_login` | 未註冊會自動建立帳號 |
| 微信開放平台 | OAuth | 後台填回呼網域；開發時可關閉真實 SMTP / 簡訊，驗證碼印在 API 日誌 |

登入回應帶 `access_token`。之後每個需登入的請求：

```
Authorization: Bearer <access_token>
EasyTV-User: <user_id>
```

營運後台走 `/admin/*`，還要 `role ≥ 10`。改系統設定、退款、調積分要超級管理員 `role ≥ 100`（就是首次啟動那個 `admin`）。

管理員可以替某個使用者簽發一次性「控制台」憑證，開啟創作台或通路後台免密碼進入（代登入排查問題）。

## 團隊空間

創作台頂欄：**個人空間** / **團隊空間**。一個人最多屬於一個團隊。請求標頭 `EasyTV-Team: <team_id>`（未帶或 0 = 個人）。

規則：

1. 個人空間永遠花自己的錢包，即使你是某團隊成員
2. 團隊空間花 **團隊 owner 的積分池**；owner 的團隊版會員過期則拒絕（`team_expired`）
3. 舊專案留在個人空間，作者可以把專案移進 / 移出團隊
4. 角色 `admin` / `editor` / `viewer`。檢視者不能用團隊積分生成
5. 被移出團隊時介面回傳 `team_forbidden`，前端應清掉標頭、切回個人空間

會員方案有「創作版」單席和「團隊版」多席（2–10，折扣見 `BillingPromo`）。並行路數和雲端儲存跟著方案走。
