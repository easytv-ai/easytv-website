title: Модели
description: Доступный список и детали. Список — это model_price.status=1, единственный белый список для создания задач.
---

Оба маршрута **анонимные**. Получите список, затем передайте `model` в `POST /user/task`. Если шлюз не настроен или таблица пуста, возвращается `[]`.

Каждая строка содержит цену в кредитах: `unit` (`second` / `image` / `call`), `points_per_unit`, `member_points_per_unit`, `priced`. Операторы импортируют модели со шлюза на странице [Цены](/docs/api-admin-price).
