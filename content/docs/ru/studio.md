Студия — это фронтенд для авторов, репозиторий — [easytv-web](https://github.com/easytv-ai/easytv-web). Руководства по функциям: [холст](/docs/canvas), [фильм по одной фразе](/docs/create), [режиссёрская сцена](/docs/director), [сообщество](/docs/community), [вход и команды](/docs/team).

![Главная страница студии и избранные фильмы](/images/docs/studio.png)

## Что она умеет

- **Свободный холст**: узлы текста, изображения, видео, аудио и группы раскадровки, с историей версий и общим доступом только для чтения
- **Фильм по одной фразе**: план, персонажи, сцены, кадры и озвучка, затем доводка кадр за кадром
- **3D-режиссёрская сцена**: мизансцена и камеры в браузере; описания кадров записываются обратно на холст
- **Монтаж в браузере**: обрезка, разделение и склейка через FFmpeg.wasm
- **Сообщество**: обзор, подписки, рейтинги, комментарии, публичный плеер
- **Навыки и промпты**: повторно используемые шаблоны процессов
- **Семь языков**: упрощённый / традиционный китайский, английский, французский, японский, русский, вьетнамский

## Маршруты

| Путь | Значение |
| --- | --- |
| `/agent` | Главная (`/` перенаправляет сюда с кодом 301) |
| `/explore` `/studio` `/following` `/rank` | Лента, избранное, подписки, рейтинги |
| `/create` | Фильм по одной фразе: промпт → план → генерация по слоям → монтаж |
| `/canvas` | Свободный холст. `?id=` открывает существующий, `?project_id=` создаёт из проекта |
| `/canvas/director` | 3D-режиссёрская сцена; сцена записывается обратно на тот же холст |
| `/share/:token` | Общий доступ к холсту только для чтения |
| `/projects` `/assets` `/subjects` `/prompts` | Проекты и библиотеки |
| `/skills` | Витрина навыков |
| `/watch/:id` | Публичный плеер |
| `/pricing` | Тарифы |
| `/settings` | Аккаунт, команда, заказы, счета, приглашения |
| `/legal/*` | Условия, конфиденциальность, правила использования ИИ (образцы текстов — проверьте перед запуском) |

## Развёртывание

Пресет Cloudflare Workers:

```bash
cp .env.example .env.production
pnpm deploy
```

Хост с Node: `NITRO_PRESET=node-server pnpm build`, затем `node .output/server/index.mjs`.

Docker:

```bash
docker run -d -p 3005:3005 \
  -e NUXT_PUBLIC_API_BASE_URL=https://api.example.com \
  -e NUXT_PUBLIC_SITE_URL=https://studio.example.com \
  ghcr.io/easytv-ai/easytv-web:latest
```
