Нужна [авторизация](/docs/api-auth). Публичные цены берутся из `/billing/plans` в разделе [Заказы](/docs/api-order).

Кредиты хранятся партиями; **первыми расходуются партии с самым ранним сроком**. Баланс — сумма остатков неистёкших партий. `EasyTV-Team` переключает на пул команды.
