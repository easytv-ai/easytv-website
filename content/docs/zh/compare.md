---
title: 和其他方案对比
description: 自托管 EasyTV 和商业短剧 SaaS 差在哪。商业平台列以各家公开说明为准。
---

EasyTV 要的是把短剧生产线放在你自己的服务器上，模型仍走你自己的网关。

| | EasyTV | 商业 SaaS（LibTV 等） |
| --- | --- | --- |
| 源码与部署 | AGPL-3.0，部署在自己的机器 | 闭源，平台托管 |
| 模型来源 | 任意 OpenAI 兼容网关，自选厂商与价格 | 平台指定模型与价格 |
| 计费与定价 | 积分 / 会员 / 促销价自己定 | 平台定价 |
| 支付与结算 | 微信 / 支付宝直连，发票、分销、提现 | 平台代收 |
| 数据归属 | 素材、画布、成片在自己的存储 | 存在平台 |
| 团队协作 | 团队空间、角色、审批门禁 | 通常为付费团队版 |
| 多语言 | 7 语种内置 | 视平台而定 |
| 二次开发 | 契约公开，可改可扩 | 不开放 |

许可边界见 [开源协议](/docs/license)。`easytv-api` 派生自 New API / One API，不能单独改成闭源商用。
