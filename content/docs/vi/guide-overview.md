Hướng dẫn được chia theo từng mặt của sản phẩm. Người sáng tác bắt đầu từ [studio](/docs/studio); người vận hành bắt đầu từ [trang quản trị](/docs/admin).

![Studio](/images/docs/studio.png)

## Người sáng tác

| Trang | Nội dung |
| --- | --- |
| [Studio](/docs/studio) | route của easytv-web, ngôn ngữ, trỏ tới API của bạn |
| [Canvas](/docs/canvas) | nút, khóa lạc quan, phiên bản, chia sẻ |
| [Một câu thành phim](/docs/create) | nhập → kế hoạch → các lớp → dựng phim |
| [Sân khấu đạo diễn](/docs/director) | vị trí nhân vật, máy quay, ghi ngược về canvas |
| [Công cụ media](/docs/media) | ffmpeg trên trình duyệt và hậu kỳ phía máy chủ |
| [Cộng đồng](/docs/community) | bảng tin, bình luận, chia thưởng Skill |
| [Đăng nhập và nhóm](/docs/team) | email / SMS / WeChat, không gian nhóm |

## Vận hành và đối tác

| Trang | Nội dung |
| --- | --- |
| [Tính phí](/docs/billing) | điểm, gói hội viên, WeChat / Alipay |
| [Trang quản trị](/docs/admin) | người dùng, kiểm duyệt, giá, gateway |
| [Trang đối tác](/docs/partner) | hoa hồng, rút tiền, bộ tài liệu quảng bá |
| [Gateway](/docs/gateway) | lấy mô hình, nhập bảng giá |

Bảng đối chiếu giữa trang và route nằm ở [Tổng quan API](/docs/api).
