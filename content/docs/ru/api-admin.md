---
title: API администратора
description: Маршруты /admin/* для админ-панели. role ≥ 10; для настроек, возвратов и корректировок кредитов нужна role ≥ 100.
---

Вызывающая сторона — [easytv-manage](https://github.com/easytv-ai/easytv-manage). Авторизация та же, что и у [пользователей](/docs/api-auth-login), плюс роль администратора.

RootAuth (`role ≥ 100`) требуется для настроек, удаления пользователей, перепривязки, квот, выплат, возвратов / отметки «оплачено», корректировок кредитов и изменения тарифов / пакетов / акций / цен на модели. Обычные администраторы получают `权限不足`.

Подробные группы — в меню слева: пользователи, модерация, цены.
