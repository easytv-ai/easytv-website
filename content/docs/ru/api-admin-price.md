---
title: Цены и шлюз
description: Тарифы, пакеты кредитов, цены на модели, загрузка и импорт со шлюза, возвраты и корректировки кредитов.
---

Изменение тарифов / пакетов / цен, возвраты и корректировки требуют **RootAuth** (`role ≥ 100`). Обычным администраторам доступно только чтение. `model` должен совпадать с идентификатором на шлюзе — это единственный источник данных для `GET /generation/models`.
