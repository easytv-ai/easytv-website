EasyTV はオープンソースでセルフホスト可能な AI ショートドラマ制作プラットフォームです。クリエイターはブラウザ上で、ひと言のアイデアを完成映像に仕上げます。ノードキャンバスは脚本、カット、画像、動画、音声を扱い、3D ディレクターステージは動線とカメラ位置を担当し、ワンプロンプト制作のパイプラインは企画、生成、合成を自動で行います。課金、モデル価格設定、決済、管理コンソールはすべて内蔵されています。

モデルは引き続きあなた自身の OpenAI 互換ゲートウェイを経由し、EasyTV は制作ワークフローと運用を担当します。

## 4 つのリポジトリ

| リポジトリ | 役割 | 既定のポート |
| --- | --- | --- |
| [easytv-api](https://github.com/easytv-ai/easytv-api) | Go バックエンド：認証、キャンバス、エージェント、合成、課金、ストレージ | 8383 |
| [easytv-web](https://github.com/easytv-ai/easytv-web) | スタジオ：キャンバス、ワンプロンプト制作、ディレクターステージ、コミュニティ | 3005 |
| [easytv-manage](https://github.com/easytv-ai/easytv-manage) | 管理コンソール：ユーザー、審査、価格設定、ゲートウェイ、グロース | 3006 |
| [easytv-partner](https://github.com/easytv-ai/easytv-partner) | パートナー向けセルフサービスコンソール：報酬、出金、販促素材 | 3010 |

公式サイト（このサイト）は [easytv-website](https://github.com/easytv-ai/easytv-website) にあり、制作の経路には関与しません。画面は [はじめに](/docs) を参照してください。

## どんな人に向いているか

- ショートドラマ / ショート動画の AI 制作環境を自前で構築し、モデルとデータを自分で管理したい
- OpenAI 互換のモデルゲートウェイをすでに持っている（またはこれから構築する）
- 生成 API をいくつか呼び出すだけでなく、クレジット課金、会員、決済、審査用の管理画面が必要

## クリエイター向けの機能

- [フリーキャンバス](/docs/canvas)：テキスト / 画像 / 動画 / 音声 / 絵コンテ / ディレクターステージのノード
- [ワンプロンプト制作](/docs/create)：企画書 → レイヤーごとの生成 → 合成
- [3D ディレクターステージ](/docs/director)：立ち位置とカメラ位置をキャンバスに書き戻し
- [メディアツール](/docs/media)：ffmpeg によるトリミングとフレーム抽出、能力タグに応じた超解像 / 字幕除去
- [コミュニティとスキル](/docs/community)：完成映像の公開、スキルの収益分配
- [ログインとチーム](/docs/team)：メール / SMS / WeChat、個人スペースとチームスペース

## 運用向けの機能

- [管理コンソール](/docs/admin)：ユーザー、審査、価格設定、決済、グロース
- [ゲートウェイ連携](/docs/gateway) と [課金](/docs/billing)
- [パートナーコンソール](/docs/partner)：報酬、出金、販促素材
- [オブジェクトストレージ](/docs/storage) と [本番デプロイ](/docs/deploy)

## やらないこと

EasyTV はモデルゲートウェイ **ではありません**。テキスト、画像、動画、音声のリクエストは、すべてあなたが設定した OpenAI 互換ゲートウェイに転送されます。ゲートウェイがない場合、スタジオは開けますが、生成は動きません。
