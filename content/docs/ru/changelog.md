Эта страница — срез изменений, заметных в документации. Каждый репозиторий продукта ведёт собственный `CHANGELOG.md`.

## Сайт документации easytv-website

- Двуязычная документация на `/docs` и `/en/docs`: Начало, Установка, Руководства, Справочник API, Помощь
- Тема следует главной странице; документация больше не принуждает к тёмной теме
- Подписи на схеме архитектуры больше не перекрывают блоки API / шлюза
- pnpm, AGPL-3.0, заметки об участии и безопасности

## Студия easytv-web

- Docker-образ и `NUXT_PUBLIC_*` во время выполнения
- Двойная лицензия: AGPL-3.0 плюс шаблон коммерческой лицензии
- Список разрешённых хостов медиапрокси теперь берётся из конфигурации времени выполнения

## API easytv-api

- Контрактом по-прежнему остаётся `API.md` в этом репозитории (до главы 38 включительно)
- Генерация обращается только к шлюзу, совместимому с OpenAI
- Кредиты предварительно списываются по `model_price` и возвращаются при сбое или отмене

Невыпущенные изменения — в разделе `[Unreleased]` журнала изменений каждого репозитория.
