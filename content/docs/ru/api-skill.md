---
title: Навыки
description: Официальный каталог, личные навыки, избранное. Текстовые задачи со skill_id получают правила выполнения навыка.
---

Официальный список анонимный — см. `GET /skill` в разделе [Публичный API](/docs/api-public). Эта группа — собственные навыки вошедшего пользователя.

`guide` + `output_format` — это правила выполнения; они добавляются в начало промпта, когда в `POST /user/task` указаны `skill_id` и `type=text`. В задачи на изображения / видео они не добавляются.
