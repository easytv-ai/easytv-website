---
title: 和其他方案比較
description: 自架 EasyTV 和商業短劇 SaaS 差在哪。商業平台欄以各家公開說明為準。
---

EasyTV 要的是把短劇產線放在你自己的伺服器上，模型仍走你自己的閘道。

| | EasyTV | 商業 SaaS（LibTV 等） |
| --- | --- | --- |
| 原始碼與部署 | AGPL-3.0，部署在自己的機器 | 閉源，平台代管 |
| 模型來源 | 任意 OpenAI 相容閘道，自選廠商與價格 | 平台指定模型與價格 |
| 計費與定價 | 積分 / 會員 / 促銷價自己定 | 平台定價 |
| 金流與結算 | 微信 / 支付寶直連，發票、分銷、提領 | 平台代收 |
| 資料歸屬 | 素材、畫布、成片在自己的儲存 | 存在平台 |
| 團隊協作 | 團隊空間、角色、審批門禁 | 通常為付費團隊版 |
| 多語言 | 7 語系內建 | 視平台而定 |
| 二次開發 | 契約公開，可改可擴充 | 不開放 |

授權邊界見 [開源授權](/docs/license)。`easytv-api` 有部分模組衍生自上游 AGPL-3.0 開源專案，不能單獨改成閉源商用。
