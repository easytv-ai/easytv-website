title: Публичный API
description: Анонимные лента, навыки, объявления, категории, общие холсты. Запросы с авторизацией добавляют liked / favorited / mine.
---

Эти маршруты работают без входа. С заголовками авторизации у работ появляется `liked`, у навыков — `favorited`, у комментариев — `mine`. Публичный биллинг описан в разделе [Заказы](/docs/api-order), модели — в разделе [Модели](/docs/api-models).
