title: Comparatif
description: EasyTV auto-hébergé face aux SaaS commerciaux de séries courtes. La colonne SaaS s'appuie sur la documentation publique.
---

EasyTV garde la chaîne de production sur vos machines. Les modèles passent toujours par votre passerelle.

| | EasyTV | SaaS commerciaux (LibTV et similaires) |
| --- | --- | --- |
| Code source et hébergement | AGPL-3.0, sur vos serveurs | Code fermé, hébergé par l'éditeur |
| Modèles | Toute passerelle compatible OpenAI | Liste et prix de l'éditeur |
| Facturation | Vous fixez crédits, abonnements et promotions | Prix de l'éditeur |
| Paiements | WeChat / Alipay, factures, versements | Encaissés par l'éditeur |
| Données | Votre stockage objet | Stockage de l'éditeur |
| Équipes | Espace, rôles et validations intégrés | Souvent une offre payante |
| Langues | Sept langues intégrées | Variable |
| Forks | Contrat public, extensible | Fermé |

Les limites de la licence sont détaillées sur la page [licence](/docs/license). Certaines parties d'`easytv-api` dérivent de projets amont sous AGPL-3.0 ; ce dépôt ne peut donc pas, à lui seul, devenir propriétaire.
