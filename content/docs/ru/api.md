Бэкенд — это REST API из двух семейств: **создание и пользователь** и **администрирование и партнёры**. У студии, админ-панели и кабинета партнёра общий вход. **Не используйте cookie для авторизации.**

- Base URL: `NUXT_PUBLIC_API_BASE_URL`, локально — `http://127.0.0.1:8383`. В примерах curl используется `$API`.
- HTTP-статус **всегда 200**. Смотрите поле `success` в JSON.
- Временные метки — секунды Unix. Пустой `deleted_at` означает, что запись не удалена.
- Пагинация: `?page=1&page_size=20` (максимум 100).
- Мягкое удаление: `DELETE` перемещает в корзину; физическая очистка — через 30 дней.

```json
{ "success": true, "message": "", "data": {} }
{ "success": false, "message": "reason" }
```

Заголовки авторизации — `Authorization: Bearer <token>` и `EasyTV-User`. Сущности и конечные автоматы описаны в [`easytv-api/API.md`](https://github.com/easytv-ai/easytv-api/blob/main/API.md). **Сначала меняйте этот файл, затем код.**
