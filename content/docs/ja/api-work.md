---
title: 作品
description: アセットからの完成映像の公開、いいねとコメント、制作過程。公開フィードは別の匿名エンドポイント群です。
---

ログインユーザーの作品 CRUD には [認証](/docs/api-auth) が必要です。コミュニティのフィードは [公開 API](/docs/api-public) を使います。

`status`：0 下書き / 1 公開済み / 2 公開停止 / -1 審査で却下。`review_status`：0 審査待ち / 1 承認 / 2 却下。公開はブロックされず、審査は事後に行われます。制作過程を公開するには `canvas_id` が必要です。
