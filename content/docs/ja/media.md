---
title: メディアツール
description: キャンバスのツールバーにある ffmpeg アクションと、能力タグに応じて課金されるモデルアクション。
---

キャンバスのツールバーにある 20 以上の入口は、すべて `media_job` を使います。ローカルの ffmpeg アクションは無料で、実際のアセットを出力します。モデルアクションは「能力タグ」によって価格設定済みのモデルにつながります。契約は `API.md` の第 23 章にあります。

サーバーで `ffmpeg` / `ffprobe` を実行できる必要があります（`PATH` または setting の `FFmpegPath` / `FFprobePath`）。管理コンソールの **システム → メディアツール** で、特定の種類のボタンを無効にしたり、キューの上限を調整したりできます。

## ローカルアクション（無料）

ffmpeg がインストールされていない場合、このグループ全体が利用できません。

| action | 名称 | 入力 → 出力 |
| --- | --- | --- |
| `crop` | 画面のトリミング | 動画 / 画像 → 同じ種類 |
| `grid_split` | グリッド分割 | 画像 → 画像 ×N（1–25） |
| `montage` | 絵コンテグループの結合 | 画像 ×N → 1 枚のグリッド |
| `trim` | 区間の切り出し | 動画 / 音声 |
| `split` | 分割 | 1 つを 2 つに |
| `remove_silence` | 無音カット | 動画 / 音声 |
| `extract_audio` / `mute_video` / `split_av` | 音声トラック / 無音化 / 分離 | 動画 |
| `mix_bgm` | BGM のミックス | 動画 + 音声アセット |
| `extract_frame` / `extract_frames` | フレーム取得 / フレーム抽出 | 動画 → 画像 |
| `storyboard` | フレーム単位のカット分析 | フレーム抽出 + テキストモデルによる解釈 |
| `compress` | 圧縮 | 動画 / 画像 |

1 ユーザーが同時にキュー待ち / 処理中にできるのは既定で最大 3 件、全体では既定で 20 件です（管理コンソールで変更可能）。作成は 1 分あたり 30 回に制限されます。

グリッド分割は **ブラウザ上では切り出しません**。OSS に CORS がないとピクセルを読み取れないため、1 回のジョブで N 個の出力を生成します。

## モデルアクション（課金）

能力タグは `model_price.abilities` に書きます（カンマ区切り）。タグがない場合はモデル名から推定します（`*upscale*`、`*subtitle*`、`*demucs*` …）。対応する能力が設定されていないボタンは、クリックして初めてエラーになるのではなく、利用不可として表示されます。

よく使う能力タグ：`upscale`、`remove_subtitle`、`vocal_separation`、`bgm_separation`、`matting`、`subject_remove` / `modify` / `replace`、`motion_capture`、`native_audio`（トーキングヘッドでは、セリフどおりに発声できる動画モデルだけが一覧に表示されます）、`video_reference`（オムニリファレンス / ヒット作のリミックス）。

モデルアクションの作成時には、生成タスクも同期的に送信されます。クレジット不足、価格未設定、同時実行数の上限のいずれかに該当すると、エンドポイントはそのまま失敗し、ジョブは保存されません。

## ブラウザ内編集

スタジオには FFmpeg.wasm も内蔵されており、トリミング / 分割 / 結合を完全にローカルで行えます。大きなファイルや、タイムライン合成に入れる場合は、引き続きサーバー側で処理します。
