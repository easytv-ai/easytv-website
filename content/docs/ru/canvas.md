Холст — ядро студии, путь `/canvas`. `?id=` открывает существующий холст; `?project_id=` создаёт холст из проекта. API хранит `graph` как непрозрачный JSON и **не разбирает семантику узлов**. Ограничение: **2 МБ на холст**.

![Узлы и связи на холсте](/images/docs/canvas.png)

## Типы узлов

| kind | Назначение |
| --- | --- |
| `text` | Сценарий, промпты, описание по изображению. До 4 референсных изображений для моделей со зрением |
| `image` | Текст в изображение / изображение в изображение, с необязательной фиксацией персонажа и стиля |
| `video` | Текст в видео, первый / последний кадр, видеореференс, «говорящая голова» (`videoMode=talking`) |
| `audio` | Синтез речи, фоновая музыка, диалоги |
| `storyboard` | Группа раскадровки: кадры, собранные в сетку |
| `director` | [3D-режиссёрская сцена](/docs/director), записывается обратно на тот же холст |
| `panorama` | Панорамное изображение |

На пустом холсте предлагаются стартовые карточки: сценарий истории, лист персонажа в трёх проекциях, видео по универсальным референсам, «говорящая голова», фоновая музыка — или перетащите шаблон [навыка](/docs/community).

## Как проходит запуск

1. Добавьте узел, заполните промпт, выберите модель
2. Соедините узлы от вышестоящих к нижестоящим: изображения служат первым кадром / референсом, текст — промптом для изображений
3. Нажмите запуск. Клиент вызывает `POST /user/task`, затем опрашивает `GET /user/task/:id`
4. При успехе ассет сохраняется, а `content` узла становится воспроизводимым URL

Модели без цены завершаются ошибкой «模型未定价» и не создают задачу. Кредиты подчиняются правилам [биллинга](/docs/billing): сначала предварительное списание, при сбое или отмене — возврат.

Параметры видео передаются как есть: `ratio` / `resolution` / `duration` / `generate_audio` / `seed` / `negative_prompt`. Роли входных данных: `first_frame`, `last_frame`, `reference`, `reference_video`, `reference_audio`.

## Версии и общий доступ

- Автосохранения объединяются в одну запись примерно раз в 10 минут; Ctrl+S / «Сохранить» отправляет `snapshot: true`
- Не более 50 версий на холст. Перед восстановлением текущий graph сохраняется в резервную версию
- `PUT` должен передавать текущую `version`, иначе вернётся «画布已在其他地方修改，请刷新»
- Общий доступ: `GET/PUT /user/canvas/:id/share`, публичная страница `/share/<token>` (старый `/s/<token>` отвечает 301). Анонимные зрители видят очищенный graph; вошедшие пользователи могут скопировать его в свой проект

## Медиаинструменты

Обрезка, раскадровка лентой, удаление пауз, разделение аудио и видео и подобное выполняются через [медиаинструменты](/docs/media). Локальные действия ffmpeg бесплатны; апскейл, удаление вшитых субтитров, вырезание фона и прочее оплачиваются через способности моделей.

Браузер также умеет обрезать / разделять / склеивать с помощью FFmpeg.wasm. Если у бакета не настроен CORS, используйте медиапрокси студии и добавьте хост в `NUXT_PUBLIC_MEDIA_HOSTS`.
