目標は、**15 分以内** に完成映像を 1 本見ることです。以下では、ローカルマシンに Docker 24+ があり、テキスト / 画像 / 動画モデルを呼び出せる OpenAI 互換ゲートウェイのトークンを持っていることを前提とします。

より詳しいインストール方法は [インストールとデプロイ](/docs/install) を、まず機能だけ見たい場合は [スタジオ](/docs/studio) を参照してください。

## 1. 一式を起動する

```bash
git clone https://github.com/easytv-ai/easytv-api.git
cd easytv-api
cp .env.example .env
```

`.env` を編集します：

- `ROOT_PASSWORD`：最初の管理者のパスワード（ユーザー名の既定値は `admin`）
- `CRYPTO_SECRET`：`openssl rand -hex 32`

```bash
docker compose --profile full up -d
curl http://localhost:8383/healthz
```

| 開くもの | アドレス |
| --- | --- |
| API | http://localhost:8383 |
| スタジオ | http://localhost:3005 |
| 管理コンソール | http://localhost:3006 |

パートナーコンソールは個別に起動する必要があります。[パートナーコンソール](/docs/partner) を参照してください。

## 2. 管理コンソールにログインする

`http://localhost:3006` を開き、`admin` と自分で設定した `ROOT_PASSWORD` でログインします。

次の順番で設定を変更します（すべて **システム** にあり、変更はすぐに反映されます）：

1. **サイト**：スタジオの公開アドレスに `http://localhost:3005` を入力します（招待リンクと決済コールバックの両方に使われます）
2. **ゲートウェイ**：OpenAI 互換ゲートウェイの Base URL と Key を入力 → モデルを取得 → **価格を取り込み**
3. **モデル価格**：取り込んだテキスト / 画像 / 動画の単価を確認します（価格が設定されていないモデルは、スタジオで生成できません）

詳細は [ゲートウェイ連携](/docs/gateway) を参照してください。

## 3. 管理者にクレジットを追加する

生成にはクレジットが必要です。管理コンソールの **ユーザー** で `admin` を探し、「クレジットを調整」でテスト用の額を付与します（または、先に自分に会員プランを付与します）。

スタジオの `/pricing` から決済することもできますが、ローカルでの動作確認では、まず手動で追加するのが一般的です。

## 4. ワンプロンプト制作を 1 本実行する

`http://localhost:3005/create` を開きます（未ログインの場合はログインダイアログが表示されるので、同じ `admin` アカウントを使います）。

1. ひと言を入力し、長さ 15 / 30 / 60 秒を選びます
2. 企画書を生成します（テキストモデルのクレジットが 1 回分引き落とされます）
3. キャラクター、シーン、カットを確認し、「キャンバスを作成」を押します
4. キャラクター画像、カット画像、カット動画、ナレーションをレイヤーごとに生成します
5. 合成：ffmpeg による結合、字幕の焼き込み、BGM のミックス。無料アカウントには透かしが入ります

完全な手順は [ワンプロンプト制作](/docs/create) を参照してください。
