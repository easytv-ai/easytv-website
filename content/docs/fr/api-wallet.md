---
title: Portefeuille
description: Solde, lots, mouvements, abonnement. Les crédits sont la seule unité ; ignorez l'ancien quota.
---

Nécessite l'[authentification](/docs/api-auth). La tarification publique utilise `/billing/plans`, sous [Commandes](/docs/api-order).

Les crédits sont répartis en lots ; **ceux qui expirent le plus tôt sont consommés en premier**. Le solde est la somme des restes non expirés. `EasyTV-Team` bascule sur la réserve de l'équipe.
