创作台不只是工作台，也有一条公开的成片社区。运营在后台审作品、评论和技能。

## 作品

创作者从资产发布：`POST /user/work`。公开信息流 `GET /work`，详情 `/watch/:id`（浏览数 +1）。作者可选择公开「制作过程」`/process/:id`。

创作台路由：

| 路径 | 说明 |
| --- | --- |
| `/explore` | 信息流，精选优先 |
| `/studio` | 推荐 |
| `/following` | 关注 |
| `/rank` | 榜单 |
| `/author/:id` | 作者主页 |
| `/watch/:id` | 播放 |

点赞、评论、举走登录接口。运营在 **作品 / 社区审核 / 举报** 里上下架、处理举报。精选成片和首页轮播在后台单独排。

## 技能

技能是可复用的工作流模板（提示词 + 可选画布 graph）。

- 广场 `/skills`：官方 + 已过审的用户技能
- 创作者提交 `POST /user/skill/:id/submit`，运营在 **技能** 页审核
- 别人用你的技能会记分成；收益可兑积分或提现人民币（汇率 `GrowthPointsPerYuan`，默认 20 积分/元）

后台还可以维护提示词库、风格库、主体库（角色三视图），给画布当参考。

## 增长

邀请码 `/invite/:code`、渠道码 `/partner/:code` 或 `/p/:code`、口令红包，注册时写入归属。规则在后台 **系统 → 增长**：注册送分、签到、邀请奖励、归因窗口。渠道侧见 [渠道后台](/docs/partner)。

活动页 `/campaign`，运营在 **活动** 里配。
