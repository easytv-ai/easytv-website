プロダクトリポジトリは **AGPL-3.0 + 商用** のデュアルライセンスを採用しています：

| リポジトリ | ライセンス |
| --- | --- |
| easytv-api / web / manage / partner | AGPL-3.0。商用ライセンスのテンプレートを別途同梱 |
| easytv-website | AGPL-3.0 のみ（紹介サイト。ライセンスの販売なし） |

## AGPL だけで足りる場合

学習、改変、セルフホストでのデプロイを行い、かつ AGPL を守る場合です（改変版をネットワークサービスとして他者に提供するときは、対応するソースコードを公開する必要があります）。**AGPL は商用利用を認めています**。ネットワーク経由の利用にコピーレフトが及ぶだけです。

## 商用ライセンスが必要な場合

クローズドソースの製品、または改変版を SaaS / ホワイトラベルとしてホストし、かつ上記のソース公開義務を負いたくない場合です。リポジトリにある `COMMERCIAL-LICENSE.md` はテンプレートであり、双方が注文書を締結して初めて効力を持ちます。

[leida@easyapi.com](mailto:leida@easyapi.com) までメールでご連絡ください。件名に `[LICENSE] easytv-api`（または該当するリポジトリ名）を付けてください。

## サードパーティ

- ディレクターステージは [open-director](https://github.com/x1n9/open-director)（MIT）からの移植です
- API のユーザー / 決済 / オブジェクトストレージの構造は、[One API](https://github.com/songquanpeng/one-api) などの上流オープンソースプロジェクトを参考にしています。**商用ライセンスでもこれらの部分のライセンスは変わりません**
- npm / Go の依存パッケージは、それぞれ元のライセンスに従います
