EasyTV — открытая ИИ-студия коротких сериалов, которую можно развернуть у себя. В браузере вы превращаете идею из одной строки в готовый фильм: холст из узлов для сценариев, раскадровок, изображений, видео и аудио; 3D-режиссёрская сцена для мизансцен и камер; конвейер «фильм по одной фразе», который планирует, генерирует и монтирует. Кредиты, цены на модели, платежи и админ-панель уже встроены.

Запросы к моделям по-прежнему идут через ваш собственный шлюз, совместимый с OpenAI. EasyTV отвечает за творческий процесс и эксплуатацию.

## Четыре репозитория

| Репозиторий | Роль | Порт по умолчанию |
| --- | --- | --- |
| [easytv-api](https://github.com/easytv-ai/easytv-api) | Бэкенд на Go: авторизация, холст, агент, монтаж, биллинг, хранилище | 8383 |
| [easytv-web](https://github.com/easytv-ai/easytv-web) | Студия: холст, фильм по одной фразе, режиссёрская сцена, сообщество | 3005 |

Сайт проекта — [easytv-website](https://github.com/easytv-ai/easytv-website); в процессе создания он не участвует. Скриншоты — на странице [Начало работы](/docs).

## Для кого это

- Вам нужна своя ИИ-платформа для коротких сериалов / коротких видео на собственных серверах, а модели и данные остаются у вас
- У вас уже есть (или появится) шлюз моделей, совместимый с OpenAI
- Вам нужны кредиты, тарифы, платежи и модерация, а не просто несколько вызовов генерации

## Для авторов

- [Свободный холст](/docs/canvas): узлы текста / изображения / видео / аудио / раскадровки / режиссёрской сцены
- [Фильм по одной фразе](/docs/create): план → генерация по слоям → монтаж
- [3D-режиссёрская сцена](/docs/director): мизансцена и камеры записываются обратно на холст
- [Медиаинструменты](/docs/media): обрезка и раскадровка лентой через ffmpeg, а также апскейл / удаление субтитров при наличии нужных способностей у моделей
- [Сообщество и навыки](/docs/community): публичные фильмы, выплаты за навыки
- [Вход и команды](/docs/team): e-mail / SMS / WeChat, личное и командное пространство

## Для операторов

- [Админ-панель](/docs/admin): пользователи, модерация, цены, платежи, рост
- [Шлюз](/docs/gateway) и [биллинг](/docs/billing)
- [Кабинет партнёра](/docs/partner): вознаграждения, вывод средств, промоматериалы
- [Хранилище](/docs/storage) и [продакшен](/docs/deploy)

## Чем EasyTV не является

EasyTV — **не** шлюз моделей. Вызовы текста, изображений, видео и аудио пересылаются на настроенный вами шлюз, совместимый с OpenAI. Без шлюза студия всё равно открывается, но генерация не работает.
