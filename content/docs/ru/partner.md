Кабинет партнёра работает с маршрутами `/user/partner/*`, репозиторий — [easytv-partner](https://github.com/easytv-ai/easytv-partner). Партнёры входят под обычной учётной записью EasyTV, подают заявку и после одобрения получают реферальную ссылку и код.

## Что может партнёр

| Раздел | Примечания |
| --- | --- |
| Панель | Клиенты, платящие клиенты, продажи и вознаграждения; динамика за 7 / 30 / 90 дней |
| Клиенты | Замаскированные никнеймы, источник, первый платёж, сумма расходов за всё время |
| Вознаграждения и вывод средств | История операций, история выводов, заявка (Alipay / WeChat / банк) |
| Бонусные коды | Получения, регистрации, оплаченные конверсии |
| Промоматериалы | Ссылка, QR-код, тексты, правила |
| Заявка | Подача, повторная подача после отказа, изменение контактов |

Ставки вознаграждения, окна привязки и рассмотрение заявок находятся в админ-панели: **Система → Рост** и страница «Партнёры». Администраторы также могут выдать одноразовый ticket для входа в кабинет партнёра.

## Запуск

```bash
pnpm dev          # :3010
```

`NUXT_PUBLIC_API_BASE_URL` указывает на API; `NUXT_PUBLIC_STUDIO_URL` — на студию (запасной вариант для промоссылок).

Docker:

```bash
docker run -d -p 3010:3010 \
  -e NUXT_PUBLIC_API_BASE_URL=https://api.example.com \
  -e NUXT_PUBLIC_STUDIO_URL=https://studio.example.com \
  ghcr.io/easytv-ai/easytv-partner:latest
```

Администраторы могут выдать одноразовый ticket на странице «Партнёры» админ-панели и открыть `/console?ticket=` сразу в кабинете этого партнёра.
