title: 管理コンソール
description: easytv-manage で管理できるものと、公開後に最初に変更すべき設定。
---

管理コンソールは API の `/admin/*` と連携します。リポジトリは [easytv-manage](https://github.com/easytv-ai/easytv-manage) です。初回起動時に作成された `admin` アカウントでログインします。

![管理コンソール：ダッシュボード、ユーザー、審査、価格設定、ゲートウェイ](/images/docs/admin.svg)

## 管理できるもの

| 領域 | ページ |
| --- | --- |
| ユーザー | ユーザー、チームの割り当て、パートナー |
| コンテンツ | 作品、おすすめ、カテゴリ、バナー、スキル、プロンプト、スタイル、キャラクター、プロジェクト、アセット、キャンバス |
| コミュニティ | コメント / 通報 / フィードの審査、お知らせ、通知 |
| お金 | 注文、チャージ、出金、取引履歴、会員、クレジットパック、モデル価格、請求書 |
| グロース | キャンペーン、招待とチェックイン、ダッシュボード |
| システム | サイト、決済、ゲートウェイ、グロース、請求書（スーパー管理者のみ） |

ここで変更した設定は `setting` テーブルに書き込まれ、API の再起動は不要です。

システム設定（スーパー管理者のみ）は次のタブに分かれています：サイト、SMS、請求書、決済、ゲートウェイとストレージ、AI チャット、メディアツール。グロースのルール（招待、チェックイン、完成映像の既定モデル、分配の換算レート）はグロースページにあります。

## 初回公開時のチェックリスト

1. **システム → ゲートウェイ**：OpenAI 互換ゲートウェイのアドレスと Key を入力し、モデルを取得して価格を取り込む
2. **システム → サイト**：スタジオの公開アドレス（招待リンクとコールバックに使われます）
3. **システム → 決済**：プランやクレジットを販売する場合は WeChat Pay / Alipay を有効にする
4. **モデル価格**：モデルごとにクレジット単価を調整する

## 実行

```bash
pnpm dev          # :3006
```

```bash
docker run -d -p 3006:3006 \
  -e NUXT_PUBLIC_API_BASE_URL=https://api.example.com \
  -e NUXT_PUBLIC_STUDIO_URL=https://studio.example.com \
  -e NUXT_PUBLIC_PARTNER_URL=https://partner.example.com \
  ghcr.io/easytv-ai/easytv-manage:latest
```

`NUXT_PUBLIC_PARTNER_URL` は、パートナーページの「パートナーコンソールを開く」で使われます。バックエンドがない場合、ログインページにはデモアカウントがあり、画面を見ることだけができます。管理コンソールに入るにはロール `role ≥ 10` が必要で、ゲートウェイ / 決済 / サイトの変更にはスーパー管理者（`role ≥ 100`）が必要です。
