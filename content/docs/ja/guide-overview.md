---
title: 機能ガイドの概要
description: ガイドの各ページが何をカバーするか。スタジオから運用、パートナーまで。
---

「ガイド」はプロダクトの画面ごとにページを分けています。制作は [スタジオ](/docs/studio) から、運用は [管理コンソール](/docs/admin) から始めてください。

![スタジオ](/images/docs/studio.png)

## クリエイター

| ページ | 内容 |
| --- | --- |
| [スタジオ](/docs/studio) | easytv-web のルート、7 言語、自分の API への向け方 |
| [フリーキャンバス](/docs/canvas) | ノード、楽観ロック、バージョン、読み取り専用の共有 |
| [ワンプロンプト制作](/docs/create) | 入力 → 企画書 → レイヤーごとの生成 → 合成 |
| [3D ディレクターステージ](/docs/director) | 立ち位置、カメラ位置、キャンバスへの書き戻し |
| [メディアツール](/docs/media) | ブラウザの ffmpeg とサーバー側の後処理 |
| [コミュニティとスキル](/docs/community) | 作品フィード、コメント、Skill の収益分配 |
| [ログインとチーム](/docs/team) | メール / SMS / WeChat、チームスペース |

## 運用とパートナー

| ページ | 内容 |
| --- | --- |
| [課金と決済](/docs/billing) | クレジット、会員、WeChat Pay / Alipay |
| [管理コンソール](/docs/admin) | ユーザー、審査、価格設定、ゲートウェイ |
| [パートナーコンソール](/docs/partner) | 報酬、出金、販促素材 |
| [ゲートウェイ連携](/docs/gateway) | モデルの取得、価格の取り込み |

API と画面の対応は、[API リファレンス](/docs/api) の対応表を参照してください。
