Ces routes fonctionnent sans connexion. Avec les en-têtes d'authentification, les œuvres incluent `liked`, les skills `favorited` et les commentaires `mine`. La facturation publique se trouve sous [Commandes](/docs/api-order) ; les modèles sous [Modèles](/docs/api-models).
