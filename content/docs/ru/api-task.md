---
title: Задачи генерации
description: Создание, опрос, отмена, повтор. Кредиты сначала списываются предварительно; модель должна быть в действующем списке model_price.
---

Нужна [авторизация](/docs/api-auth). Эту группу используют генерация из инспектора холста и текстовая задача чата. Список моделей анонимный — см. [Модели](/docs/api-models).

Состояния: `pending` → `running` → `succeeded` / `failed` / `cancelled`.

- Кредиты **списываются предварительно** (freeze) при создании, при успехе выполняется `settle`, при сбое или отмене — `unfreeze` (партии на 365 дней).
- `params.count` должен быть равен 1.
- Неизвестная `model` возвращает `模型暂未接入`, и ничего не сохраняется.
- При нехватке баланса возвращается `积分不足，还需 N 积分`.
- Генерация идёт только через шлюз, совместимый с OpenAI.
