Цель — готовый ролик **примерно за 15 минут**. Понадобятся Docker 24+ и токен шлюза, совместимого с OpenAI, который может вызывать модели текста, изображений и видео.

Другие способы установки: [Установка](/docs/install). Обзор возможностей: [Студия](/docs/studio).

## 1. Поднимите сервисы

```bash
git clone https://github.com/easytv-ai/easytv-api.git
cd easytv-api
cp .env.example .env
```

Отредактируйте `.env`:

- `ROOT_PASSWORD` — пароль первого администратора (имя пользователя по умолчанию — `admin`)
- `CRYPTO_SECRET` — `openssl rand -hex 32`

```bash
docker compose --profile full up -d
curl http://localhost:8383/healthz
```

| Что открыть | URL |
| --- | --- |
| API | http://localhost:8383 |
| Студия | http://localhost:3005 |
| Админ-панель | http://localhost:3006 |

Кабинет партнёра запускается отдельно; см. [Кабинет партнёра](/docs/partner).

## 2. Войдите в админ-панель

Откройте http://localhost:3006 и войдите как `admin` со своим `ROOT_PASSWORD`.

Меняйте настройки в таком порядке (все — в разделе **Система**, применяются сразу):

1. **Сайт**: публичный адрес студии `http://localhost:3005` (для приглашений и обратных вызовов платежей)
2. **Шлюз**: Base URL и Key шлюза, совместимого с OpenAI → загрузить модели → **импортировать цены**
3. **Цены на модели**: проверьте цены за единицу для текста / изображений / видео (модели без цены не могут генерировать)

Подробнее: [Подключение шлюза](/docs/gateway).

## 3. Начислите администратору кредиты

Генерация расходует кредиты. На странице **Пользователи** найдите `admin` и начислите тестовую партию (или оформите тариф подписки).

Можно и оплатить на `/pricing`, но для локальных тестов обычно просто пополняют баланс вручную.

## 4. Запустите фильм по одной фразе

Откройте http://localhost:3005/create (войдите под той же учётной записью `admin`).

1. Введите фразу, выберите 15 / 30 / 60 секунд
2. Сгенерируйте план (одно списание за текстовую модель)
3. Проверьте персонажей, сцены и кадры, затем **соберите холст**
4. Сгенерируйте по слоям изображения персонажей, изображения кадров, видео кадров и озвучку
5. Монтаж: склейка через ffmpeg, вшивание субтитров, фоновая музыка; бесплатные аккаунты получают водяной знак

Полное описание: [Фильм по одной фразе](/docs/create).
