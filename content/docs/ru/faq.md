## Студия открывается, но ничего не генерируется

Нет API либо не настроены шлюз или цены на модели. Укажите в `NUXT_PUBLIC_API_BASE_URL` работающий API, затем [подключите шлюз](/docs/gateway).

## Фронтенды в Docker не могут достучаться до API

Браузер обращается к вашей машине, а не к `api:8383` в сети compose. Задайте в `PUBLIC_API_URL` адрес, который может открыть браузер, например `http://192.168.x.x:8383`.

## Запуск завершается ошибкой из-за отсутствия администратора

`ROOT_PASSWORD` пуст. Если в базе данных нет администратора, API отказывается запускаться.

## Не приходит код подтверждения

В разработке задайте `EMAIL_VERIFICATION_ENABLED=false`; код выводится в лог API. Для продакшена подключите SMTP или SMS.

## Не работает обрезка медиа / CORS

Если у бакета не настроен CORS, пусть студия использует серверный медиапрокси; добавьте хост бакета в `NUXT_PUBLIC_MEDIA_HOSTS`.

## Порт 3000 занят

Сайт проекта `easytv-website` тоже по умолчанию использует 3000. Остановите этот `nuxt dev` или задайте сайту другой порт. Студия по умолчанию работает на 3005.

## Обязательно ли использовать pnpm?

Три фронтенд-репозитория закреплены за pnpm. npm / yarn / cnpm будут конфликтовать с lock-файлом и полем `packageManager`, и установка не совпадёт с CI.

## Холст не сохраняется / «больше 2 МБ»

Весь `graph` ограничен 2 МБ. Не сохраняйте снимки камер режиссёрской сцены (PNG в base64); фронтенд уже удаляет их при сохранении.

## Задачи остаются в состоянии pending

Кто-то должен обрабатывать задания. На нескольких узлах проверьте `WORKER_TAG`. Поищите в логах 429 от шлюза / модерацию / `unsupported duration`.

## Видео по изображению не работает, а по тексту — работает

Шлюз не может получить исходный URL запросом GET. Локальному диску нужен публичный `UploadBaseUrl`; OSS / Qiniu нужен публичный хост. См. [Хранилище](/docs/storage).

## Цены для подписчиков не применяются

В личном пространстве учитывается *ваша* активная подписка. В командном пространстве — командный тариф **владельца**. Наблюдатели (viewer) генерировать не могут.

## Обратный вызов платежа: 404 / неверная подпись

`ServerAddress` должен быть публичным корневым https-адресом API. Адреса уведомлений WeChat и Alipay должны вести на `/wechat/webhook` и `/alipay/webhook`.

## Можно ли использовать это в закрытом коммерческом продукте?

По AGPL-3.0 — да, если вы публикуете соответствующий исходный код, когда предлагаете изменённую версию как сетевой сервис. Покупать лицензию для этого не нужно. Закрытый код или white-label без этих обязательств требуют [коммерческой лицензии](/docs/license). Модули `easytv-api`, основанные на сторонних проектах под AGPL, остаются под AGPL.
