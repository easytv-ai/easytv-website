---
title: Команда
description: Командное пространство, приглашения, места. Генерация расходует пул команды, только если задан EasyTV-Team.
---

Нужна [авторизация](/docs/api-auth).

- Заголовок отсутствует / `EasyTV-Team: 0`: личное пространство, собственный кошелёк.
- `EasyTV-Team: <team_id>`: командное пространство, предварительное списание из пула владельца.

Пользователь состоит только в одной команде. Покупка командного тарифа делает вас владельцем; число мест берётся из заказа (2–10).
