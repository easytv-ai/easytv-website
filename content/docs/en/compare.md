title: Compare
description: Self-hosted EasyTV versus commercial short-drama SaaS. SaaS column follows public docs.
---

EasyTV keeps the production line on your machines. Models still go through your gateway.

| | EasyTV | Commercial SaaS (LibTV and similar) |
| --- | --- | --- |
| Source and host | AGPL-3.0, your servers | Closed, vendor hosted |
| Models | Any OpenAI-compatible gateway | Vendor list and prices |
| Billing | You set credits, plans, promos | Vendor prices |
| Payments | WeChat / Alipay, invoices, payouts | Vendor collects |
| Data | Your object storage | Vendor storage |
| Teams | Space, roles, approval built in | Usually a paid tier |
| Locales | Seven bundled | Varies |
| Forks | Public contract, you can extend | Closed |

License limits are on [license](/docs/license). `easytv-api` derives from New API / One API and cannot be closed-source on its own.
