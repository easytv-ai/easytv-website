Функции сверены с коммерческими платформами для коротких сериалов. Холст, режиссёрская сцена и инструменты монтажа уже работают; оставшееся перечислено в [журнале изменений](/docs/changelog) и в планах на главной странице.

![Главная страница студии](/images/docs/studio.png)

## Создание

- **Бесконечный холст**: узлы текста, изображения, видео, аудио, раскадровки и режиссёрской сцены. См. [холст](/docs/canvas)
- **Фильм по одной фразе**: план, персонажи, кадры, озвучка, затем доводка. См. [фильм по одной фразе](/docs/create)
- **Библия сериала**: биографии, мир, список серий, отметки правок на затронутых кадрах
- **3D-режиссёрская сцена**: мизансцена и камеры в браузере. См. [режиссёрская сцена](/docs/director)
- **Персонажи и стили**: фиксация по трём проекциям; официальные стили плюс восстановленные по изображению
- **Дубли и монтаж**: точки входа и выхода, сведение, SRT, ffmpeg на сервере
- **Медиаинструменты**: обрезка, разделение, кадры, дорожки, паузы, расшифровка. См. [медиаинструменты](/docs/media)
- **Повторение**: скопируйте публичный холст и запустите его заново

## Эксплуатация

- **Навыки и агент**: повторно используемые графы; помощник, который видит текущий холст
- **Командное пространство**: личное / командное, роли, согласования, общие кредиты. См. [команды](/docs/team)
- **Кредиты, тарифы, цены**: единицы для каждой модели, предварительное списание и возврат. См. [биллинг](/docs/billing)
- **Платежи, счета, партнёрская программа**: WeChat / Alipay, счета, выплаты партнёрам. См. [кабинет партнёра](/docs/partner)
- **Админ-панель**: пользователи, модерация, заказы, состояние моделей, баланс шлюза, аудит. См. [админ-панель](/docs/admin)
- **Семь языков**: zh, zh-TW, en, fr, ja, ru, vi

## Чем EasyTV не является

EasyTV — **не** шлюз моделей. Без адреса шлюза, совместимого с OpenAI, страницы открываются, но генерация не работает. См. [шлюз](/docs/gateway).
