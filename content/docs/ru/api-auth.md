У студии, админ-панели и кабинета партнёра общий вход. **Не используйте cookie для авторизации.** `$API` по умолчанию — `http://127.0.0.1:8383`.

Заголовки, тело запроса и ответы 200 для каждого маршрута — в подменю слева.

## Заголовки

| Заголовок | Когда | Примечания |
| --- | --- | --- |
| `Authorization` | `/user/*`, `/admin/*` | `Bearer <access_token>` |
| `EasyTV-User` | там же | id текущего пользователя; должен совпадать с токеном |
| `EasyTV-Team` | необязательно | id командного пространства. Отсутствует / `0` — личное пространство |
| `Content-Type` | тело JSON | `application/json` |
| `Accept-Language` | детали модели | Пересылается шлюзу |

Для `/admin/*` также нужна `role ≥ 10`. Для настроек, возвратов и корректировок кредитов нужна `role ≥ 100` (RootAuth). Для командного пространства добавьте `EasyTV-Team`. Генерация в командном пространстве расходует пул владельца; в личном пространстве всегда расходуется кошелёк вызывающего пользователя.

## Формат ответа

HTTP-статус **всегда 200**. Смотрите поле `success` в JSON. Отсутствие доступа и отсутствие ресурса одинаково возвращают `资源不存在`, поэтому проверить существование ресурса перебором нельзя. Некоторые маршруты добавляют `code` (`not_applied` / `not_approved` в кабинете партнёра).

## Частые ошибки

| message | Значение |
| --- | --- |
| `无效的参数` | Некорректный JSON или пустое обязательное поле |
| `用户名或密码错误` | Вход не выполнен |
| `资源不存在` | Ресурса нет или нет доступа |
| `权限不足` | Администратор вызвал маршрут RootAuth |
| `积分不足，还需 N 积分` | Недостаточно кредитов для создания задачи |
| `模型未定价` / `模型暂未接入` | `model` нет в действующем списке `model_price` |
