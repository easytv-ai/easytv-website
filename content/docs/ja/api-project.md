---
title: プロジェクト
description: 作品の入れ物。キャンバスはプロジェクトに属し、project_id なしでキャンバスを作成するとバックエンドが同名のプロジェクトを自動で作成します。
---

[認証](/docs/api-auth) が必要です。呼び出し元はスタジオの `/projects` です。

エンティティのフィールド：`id`、`user_id`、`name`、`description`、`cover_url`、`status`、`canvas_id`（読み取り専用。最後に更新されたキャンバス）、タイムスタンプ。一覧で `cover_url` が空の場合は直近の画像 1 枚が付与されますが、データベースには書き戻しません。カードをクリックしてキャンバスを開くときは、返された `canvas_id` を使います。
