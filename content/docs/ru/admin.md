Админ-панель работает с маршрутами `/admin/*` бэкенда, репозиторий — [easytv-manage](https://github.com/easytv-ai/easytv-manage). Войдите под учётной записью `admin`, созданной при первом запуске.

![Админ-панель: сводка, пользователи, модерация, цены и шлюз](/images/docs/admin.svg)

## Чем можно управлять

| Раздел | Страницы |
| --- | --- |
| Люди | Пользователи, командные квоты, партнёры |
| Контент | Работы, избранные фильмы, категории, баннеры, навыки, промпты, стили, персонажи, проекты, ассеты, холсты |
| Сообщество | Модерация комментариев / жалоб / ленты, объявления, уведомления |
| Деньги | Заказы, пополнения, вывод средств, история операций, тарифы, пакеты кредитов, цены на модели, счета |
| Рост | Акции, приглашения и ежедневные отметки, дашборды |
| Система | Сайт, платежи, шлюз, рост и счета (только суперадминистратор) |

Эти изменения записываются в таблицу `setting`; перезапускать API не нужно.

Системные настройки (только для суперадминистратора) разбиты на вкладки: сайт, SMS, счета, платежи, шлюз и хранилище, ИИ-чат, медиаинструменты. Правила роста (приглашения, ежедневные отметки, модели по умолчанию для монтажа, курс выплат) находятся на странице «Рост».

## Чек-лист первого запуска

1. **Система → Шлюз**: адрес и ключ шлюза, совместимого с OpenAI, загрузка моделей, импорт цен
2. **Система → Сайт**: публичный адрес студии (для приглашений и обратных вызовов)
3. **Система → Платежи**: WeChat Pay / Alipay, если вы продаёте тарифы или кредиты
4. **Цены на модели**: цены в кредитах для каждой модели

## Запуск

```bash
pnpm dev          # :3006
```

```bash
docker run -d -p 3006:3006 \
  -e NUXT_PUBLIC_API_BASE_URL=https://api.example.com \
  -e NUXT_PUBLIC_STUDIO_URL=https://studio.example.com \
  -e NUXT_PUBLIC_PARTNER_URL=https://partner.example.com \
  ghcr.io/easytv-ai/easytv-manage:latest
```

`NUXT_PUBLIC_PARTNER_URL` — адрес для ссылки «открыть кабинет партнёра». Без бэкенда на странице входа доступна демо-учётная запись, с которой можно только просматривать интерфейс. Требуется `role ≥ 10`; для настроек шлюза / платежей / сайта нужен суперадминистратор (`role ≥ 100`).
