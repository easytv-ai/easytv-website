## スタジオは開くが、生成できない

バックエンドに接続できていないか、ゲートウェイ / モデル価格が設定されていません。`NUXT_PUBLIC_API_BASE_URL` が稼働中の API を指していることを確認し、[ゲートウェイ連携](/docs/gateway) の手順でモデルを取り込んでください。

## Docker 内のフロントエンドから API を呼び出せない

ブラウザがアクセスするのはあなたのマシンであり、コンテナネットワーク内の `api:8383` ではありません。`PUBLIC_API_URL` を、ブラウザで開けるアドレス（例：`http://192.168.x.x:8383`）に設定してください。

## 起動時に管理者がいないというエラーが出る

`ROOT_PASSWORD` が設定されていません。システムに管理者がいない場合、API は起動を拒否します。

## 認証コードが届かない

開発時は `EMAIL_VERIFICATION_ENABLED=false` にすると、認証コードが API ログに出力されます。本番では SMTP または SMS を設定してください。

## メディアのトリミングに失敗する / CORS

オブジェクトストレージに CORS が設定されていない場合は、スタジオにサーバーサイドのメディアプロキシを使わせ、バケットのドメインを `NUXT_PUBLIC_MEDIA_HOSTS` に追加します。

## ポート 3000 が使用中

公式サイト `easytv-website` の既定ポートも 3000 です。その `nuxt dev` を止めるか、公式サイトのポートを変更してください。スタジオの既定は 3005 なので、通常は競合しません。

## pnpm を使わなければいけませんか

3 つのフロントエンドリポジトリはすべて pnpm に固定されています。npm / yarn / cnpm を使うと lockfile と `packageManager` が乱れ、インストール結果も変わってしまいます。

## キャンバスの保存に失敗する / 2 MB を超えたと表示される

`graph` 全体の上限は 2 MB です。ディレクターステージのノードにカメラ位置のスクリーンショット（base64 PNG）を書き込まないでください。フロントエンドは永続化の際にすでにこれを取り除いています。

## タスクがずっと pending のまま

API プロセスの誰かがジョブを処理する必要があります。マルチノードの場合は `WORKER_TAG` が一致しているか確認してください。ログでゲートウェイの 429 / コンテンツ審査 / `unsupported duration` を検索します。

## 画像から動画は失敗し、テキストから動画は成功する

ゲートウェイが素材の URL を取得できていません。ローカルストレージの場合は公開の `UploadBaseUrl` を設定し、OSS / Qiniu の場合は公開ドメインを使ってください。[オブジェクトストレージ](/docs/storage) を参照してください。

## 会員価格が適用されない

個人スペースでは、自分に有効な会員があるかどうかを見ます。チームスペースでは、**owner** のチーム版が有効期間内かどうかを見ます。閲覧者は生成できません。

## 決済コールバックが 404 になる / 署名検証に失敗する

`ServerAddress` は API の https ルートアドレスでなければなりません。WeChat Pay と Alipay の管理画面で設定する通知 URL は、`/wechat/webhook`、`/alipay/webhook` を指すようにします。

## クローズドソースで商用利用できますか

AGPL-3.0 を守れば（改変版をネットワークサービスとして外部に提供する際に、対応するソースコードを公開すれば）商用利用でき、ライセンスを購入する必要はありません。クローズドソースやホワイトラベルで、かつ改変を公開したくない場合は [商用ライセンス](/docs/license) が必要です。`easytv-api` のうち上流の AGPL プロジェクトから派生したモジュールは、引き続き AGPL の制約を受けます。
