## ログイン

スタジオとパートナーコンソールは、同じアカウント体系を共有します。

| 方法 | API | 説明 |
| --- | --- | --- |
| メール + パスワード | `POST /user/login` | |
| SMS 認証コード | `GET /sms/verification` + `POST /user/sms_login` | 未登録の場合は自動でアカウントが作成されます |
| WeChat オープンプラットフォーム | OAuth | 管理コンソールでコールバックのドメインを入力します。開発時は実際の SMTP / SMS を無効にでき、認証コードは API ログに出力されます |

ログインのレスポンスには `access_token` が含まれます。以降、ログインが必要なすべてのリクエストに次のヘッダーを付けます：

```
Authorization: Bearer <access_token>
EasyTV-User: <user_id>
```

管理コンソールは `/admin/*` を使い、さらに `role ≥ 10` が必要です。システム設定の変更、返金、クレジット調整にはスーパー管理者 `role ≥ 100`（初回起動時に作成される `admin` のことです）が必要です。

管理者は特定のユーザーに対して 1 回限りの「コンソール」チケットを発行でき、それを使うとスタジオまたはパートナーコンソールにパスワードなしで入れます（トラブル対応のための代理ログイン）。

## チームスペース

スタジオのヘッダー：**個人スペース** / **チームスペース**。1 人が所属できるチームは最大 1 つです。リクエストヘッダーは `EasyTV-Team: <team_id>`（省略または 0 = 個人）。

ルール：

1. 個人スペースでは、たとえどこかのチームのメンバーであっても、常に自分のウォレットを消費します
2. チームスペースでは **チームの owner のクレジットプール** を消費します。owner のチーム版会員が期限切れの場合は拒否されます（`team_expired`）
3. 既存のプロジェクトは個人スペースに残ります。作者はプロジェクトをチームに移動したり、チームから戻したりできます
4. ロールは `admin` / `editor` / `viewer`。閲覧者はチームのクレジットで生成できません
5. チームから外された場合、API は `team_forbidden` を返します。フロントエンドはヘッダーを削除し、個人スペースに戻す必要があります

会員プランには、1 シートの「クリエイター版」と複数シートの「チーム版」（2–10。割引は `BillingPromo` を参照）があります。同時実行数とクラウドストレージはプランに従います。
