功能按商业短剧工作台对齐整理。画布、导演台、智能剪辑已经能用；还在做的写在 [更新日志](/docs/changelog) 和官网上的路线图。

![创作台首页](/images/docs/studio.png)

## 创作

- **无限画布**：文本、图片、视频、音频、分镜组、导演台节点连线即跑；跨画布复制、宫格切分、连线追加提示词。见 [自由画布](/docs/canvas)
- **一句话成片**：自动策划案、角色与场景、分镜与配音，再逐镜精修。见 [一句话成片](/docs/create)
- **剧集圣经**：人物小传、世界观、集目录与修订版本，改稿后标出受影响镜头
- **3D 导演台**：浏览器里摆站位、定机位、推运镜，镜头描述写回画布。见 [导演台](/docs/director)
- **主体库与风格库**：角色三视图锁连戏；官方风格 + 从当前图反推
- **镜头候选与合成**：每镜多候选、入出点、原声混音、SRT，服务端 ffmpeg 出片
- **媒体工具**：裁切、分割、抽帧、分离音轨、去停顿、转写。见 [媒体工具](/docs/media)
- **做同款**：作品开放制作过程，一键复制画布

## 运营与商业

- **Skill 与 Agent**：可复用工作流模板，画布助手看得懂当前节点
- **团队空间**：个人 / 团队切换，角色、审批、共享积分池。见 [登录与团队](/docs/team)
- **积分、会员、模型定价**：按模型按单位定价，预扣退差，后台热更新。见 [计费](/docs/billing)
- **支付、发票、分销**：微信 / 支付宝、发票、邀请返利、渠道提现。见 [渠道后台](/docs/partner)
- **运营后台**：用户、审核、订单、模型健康、网关余额、审计。见 [运营后台](/docs/admin)
- **七语种**：简体、繁体、英、法、日、俄、越

## 不做什么

EasyTV **不是**模型网关。没有 New API / One API 兼容地址时，页面能开，生成跑不起来。对接见 [网关](/docs/gateway)。
