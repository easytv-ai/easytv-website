---
title: Œuvres
description: Publier à partir d'un asset, aimer, commenter. Le fil public est un groupe anonyme distinct.
---

Le CRUD de l'utilisateur connecté nécessite l'[authentification](/docs/api-auth). Le fil public se trouve dans l'[API publique](/docs/api-public).

`status` : 0 brouillon / 1 publiée / 2 dépubliée / -1 refusée. `review_status` : 0 en attente / 1 approuvée / 2 refusée. La publication n'est pas bloquée ; la modération a lieu a posteriori. `canvas_id` est requis pour rendre public le processus de création.
