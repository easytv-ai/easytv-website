---
title: Проекты
description: Контейнеры фильмов. Холсты привязаны к проекту; создание холста без project_id создаёт и одноимённый проект.
---

Нужна [авторизация](/docs/api-auth). Эти маршруты вызывает страница студии `/projects`.

Поля: `id`, `user_id`, `name`, `description`, `cover_url`, `status`, `canvas_id` (только чтение, последний холст), временные метки. Пустой `cover_url` в списке заполняется недавним кадром только в ответе. Открывайте холст по возвращённому `canvas_id`.
