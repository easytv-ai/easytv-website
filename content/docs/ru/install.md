Минимальный набор — **API + MySQL + шлюз, совместимый с OpenAI**. Студию и админ-панель можно добавить позже; чтобы убедиться, что бэкенд работает, достаточно `/healthz`.

## Что понадобится

| Компонент | Примечания |
| --- | --- |
| MySQL 8.x | Обязателен. При первом запуске схему создаёт AutoMigrate |
| Redis | Рекомендуется. Без него ограничение частоты и одноразовые коды работают в памяти |
| ffmpeg / ffprobe | Монтаж, извлечение кадров, отделение звука |
| Шлюз, совместимый с OpenAI | Точка входа для моделей текста / изображений / видео / аудио |
| Node.js 22.21+ и pnpm 10+ | Только если вы запускаете фронтенды из исходников |

## Какой способ выбрать

| Способ | Когда |
| --- | --- |
| [Docker Compose](/docs/install-docker) | По умолчанию. Одна команда для API; профиль `full` запускает также студию и админ-панель |
| [Запуск из исходников](/docs/install-source) | Когда вы меняете код бэкенда или фронтенда |
| Бинарный файл + systemd | Продакшен-хосты, где не должно быть Docker; возьмите сборку для Linux в GitHub Releases |

## Порты

| Сервис | Порт |
| --- | --- |
| easytv-api | 8383 |
| easytv-web | 3005 |
| easytv-manage | 3006 |
| easytv-partner | 3010 |

Если браузер работает не на localhost, задайте в `.env` значения `PUBLIC_API_URL` и `PUBLIC_STUDIO_URL` — адреса, которые браузер открывает на самом деле.
