Features are aligned with commercial short-drama workbenches. Canvas, director and edit tools already ship; leftovers live on the [changelog](/docs/changelog) and the homepage roadmap.

![Studio home](/images/docs/studio.png)

## Create

- **Infinite canvas**: text, image, video, audio, storyboard and director nodes. See [canvas](/docs/canvas)
- **One-prompt film**: plan, cast, shots, voice, then refine. See [one-prompt film](/docs/create)
- **Series bible**: bios, world, episode list, revision marks on affected shots
- **3D director**: blocking and cameras in the browser. See [director](/docs/director)
- **Subjects and styles**: three-view lock; official styles plus reverse from a still
- **Shot candidates and compose**: in/out points, mix, SRT, server ffmpeg
- **Media tools**: cut, split, frames, stems, silence, transcribe. See [media](/docs/media)
- **Remake**: copy a public canvas and rerun it

## Operate

- **Skills and agent**: reusable graphs; a helper that sees the current canvas
- **Team space**: personal / team, roles, approval, shared credits. See [teams](/docs/team)
- **Credits, plans, prices**: per-model units, reserve and refund. See [billing](/docs/billing)
- **Pay, invoice, distribution**: WeChat / Alipay, invoices, partner payouts. See [partner](/docs/partner)
- **Admin**: users, review, orders, model health, gateway balance, audit. See [admin](/docs/admin)
- **Seven locales**: zh, zh-TW, en, fr, ja, ru, vi

## What it is not

EasyTV is **not** a model gateway. Without a New API / One API compatible URL, pages open but generation does not run. See [gateway](/docs/gateway).
