---
title: Заказы и платежи
description: Расчёт цены, оформление, опрос, закрытие. Суммы в юанях (CNY); сервер пересчитывает цену, расчёт на клиенте — лишь ориентир.
---

Расчёт цены доступен анонимно; для оформления заказа нужна [авторизация](/docs/api-auth). Каналы оплаты — WeChat Native и Alipay.

`kind`: `membership` / `points`. `status`: `pending` → `paid` / `closed` / `refunded`. В продакшене обязательно задайте `ServerAddress`, иначе платёжный канал не сможет отправить обратный вызов.
