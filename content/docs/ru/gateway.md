title: Подключение шлюза

---

EasyTV вызывает модели через маршруты, совместимые с OpenAI: `/v1/chat`, `/v1/images`, `/v1/videos` (и аудио, если шлюз его предоставляет). **Чтобы генерация заработала, нужен шлюз.**

Укажите адрес и ключ шлюза в админ-панели: **Система → Шлюз**. Изменения применяются без перезапуска.

![Шлюз в админ-панели](/images/docs/admin.svg)

## Первая настройка

1. Получите токен работающего шлюза, совместимого с OpenAI, который может вызывать нужные вам модели текста / изображений / видео.
2. Войдите в админ-панель как `admin` → **Система → Шлюз**.
3. Сохраните базовый адрес и ключ шлюза.
4. Загрузите список моделей и **импортируйте цены** для моделей, которыми будете пользоваться.
5. Проверьте цены в кредитах за секунду / изображение / вызов в разделе **Цены на модели**. Оценки стоимости в студии берутся отсюда.

Ключи настроек: `EasyAPIGatewayBaseUrl`, `EasyAPIGatewayKey`, `EasyAPIGatewayEnabled`. Цены за единицу хранятся в `model_price`.

Если хост вызовов и хост цен различаются (например, `api.xxx.com` и `token.xxx.com`), задайте также `EasyAPIGatewayPricingBaseUrl`. Для реального баланса шлюза нужен «системный токен доступа» из его консоли — `EasyAPIGatewayAccessToken` (токены sk реальный баланс не показывают). Когда баланс опускается ниже `GatewayBalanceAlertUSD` (по умолчанию 20 USD), администраторы получают уведомление на сайте.

Рекомендуемые кредиты:

```
gateway USD cost × FX (7.3) × markup (3) × credits-per-yuan (20)
```

Модели с оплатой по токенам приводятся к вызову / изображению / секунде исходя из предполагаемого расхода токенов. Эти коэффициенты можно изменить. После импорта всё равно проверьте раздел **Цены на модели** — особенно цену видео за секунду и способность `native_audio` для «говорящей головы».

## Что на самом деле видит шлюз

EasyTV не вызывает SDK поставщиков. Всё проходит через `service/providers/easyapi.go`:

| Тип | Путь на шлюзе |
| --- | --- |
| Текст | `POST /v1/chat/completions` (до 4 изображений для моделей со зрением) |
| Изображение | `POST /v1/images/generations` |
| Речь | `POST /v1/audio/speech` |
| Видео | `POST /v1/videos`, затем опрос `GET /v1/videos/{job_id}` |

Ассеты передаются в `input_references[{type,url,role}]`. URL для генерации видео по изображению должны быть доступны шлюзу по GET; см. [Хранилище](/docs/storage).

При 429 / 503 запрос повторяется дважды (учитывается `Retry-After`). При 502 / 504 задание на стороне поставщика могло уже создаться, поэтому такие запросы не повторяются. Распознанные ошибки превращаются для автора в фразу на китайском языке; исходное тело ответа записывается в SysLog.

## Откуда берутся модели

EasyTV не включает SDK поставщиков. Для Kling, Jimeng, Seedance, Hailuo, Sora, GPT, Qwen, MiniMax и остальных достаточно, чтобы шлюз сопоставил их с этими маршрутами в стиле OpenAI. Смена моделей — это смена каналов шлюза, а не кода EasyTV.

## Типичные сбои

- Шлюз возвращает 200, но студия бесконечно держит задачу в очереди: проверьте в логах API ошибки поставщика и то, импортирована ли эта модель в цены.
- Настроена только чат-модель: узлы изображений / видео будут завершаться ошибкой, пока шлюз не предоставит эти маршруты.
- Base URL уже содержит `/v1`: не добавляйте ещё один `/v1` поверх того, что ожидает форма в админ-панели.
