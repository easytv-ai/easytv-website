創作台不只是工作台，也有一條公開的成片社群。營運在後台審核作品、評論和技能。

![探索頁作品流](/images/docs/explore.png)

## 作品

創作者從資產發布：`POST /user/work`。公開資訊流 `GET /work`，詳情 `/watch/:id`（瀏覽數 +1）。作者可選擇公開「製作過程」`/process/:id`。

創作台路由：

| 路徑 | 說明 |
| --- | --- |
| `/explore` | 資訊流，精選優先 |
| `/studio` | 推薦 |
| `/following` | 追蹤 |
| `/rank` | 排行榜 |
| `/author/:id` | 作者主頁 |
| `/watch/:id` | 播放 |

按讚、評論、檢舉走登入介面。營運在 **作品 / 社群審核 / 檢舉** 裡上下架、處理檢舉。精選成片和首頁輪播在後台另外排。

## 技能

技能是可重複使用的工作流範本（提示詞 + 可選畫布 graph）。

- 廣場 `/skills`：官方 + 已通過審核的使用者技能
- 創作者提交 `POST /user/skill/:id/submit`，營運在 **技能** 頁審核
- 別人用你的技能會記分潤；收益可兌換積分或提領人民幣（匯率 `GrowthPointsPerYuan`，預設 20 積分/元）

後台還可以維護提示詞庫、風格庫、主體庫（角色三視圖），給畫布當參考。

## 成長

邀請碼 `/invite/:code`、通路碼 `/partner/:code` 或 `/p/:code`、口令紅包，註冊時寫入歸屬。規則在後台 **系統 → 成長**：註冊送分、簽到、邀請獎勵、歸因窗口。通路側見 [通路後台](/docs/partner)。

活動頁 `/campaign`，營運在 **活動** 裡設定。
