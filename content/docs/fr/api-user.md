`/user/*` nécessite l'[authentification](/docs/api-auth). Le champ `quota` de `GET /user/self` est hérité : la facturation passe par le [portefeuille](/docs/api-wallet).

Les projets, les canevas et les tâches ont leurs propres groupes ; cette page ne couvre que le compte lui-même.
