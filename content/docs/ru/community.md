Студия — это ещё и открытое сообщество фильмов. Операторы модерируют работы, комментарии и навыки в админ-панели.

![Лента «Обзор»](/images/docs/explore.png)

## Работы

Авторы публикуют работу из ассета: `POST /user/work`. Публичная лента — `GET /work`, плеер — `/watch/:id` (счётчик просмотров +1). Автор может открыть процесс создания на `/process/:id`.

Маршруты студии:

| Путь | Значение |
| --- | --- |
| `/explore` | Лента, сначала избранное |
| `/studio` | Рекомендации |
| `/following` | Подписки |
| `/rank` | Рейтинги |
| `/author/:id` | Автор |
| `/watch/:id` | Плеер |

Для лайков, комментариев и жалоб нужен вход. В админ-панели разделы **Работы / модерация сообщества / жалобы** снимают материалы с публикации. Избранные фильмы и баннеры главной страницы планируются отдельно.

## Навыки

Навык — это повторно используемый процесс (промпт + необязательный graph холста).

- Витрина `/skills`: официальные навыки и одобренные навыки пользователей
- Авторы отправляют навык через `POST /user/skill/:id/submit`; модерация — в разделе **Навыки** админ-панели
- Когда ваш навык запускают другие, вам начисляется доля; выплата — кредитами или в юанях (курс `GrowthPointsPerYuan`, по умолчанию 20 кредитов за юань)

В админ-панели также ведутся библиотека промптов, библиотека стилей и библиотека персонажей (листы в трёх проекциях) — как референсы для холста.

## Рост

Приглашение `/invite/:code`, партнёр `/partner/:code` или `/p/:code`, бонусные коды — привязка записывается при регистрации. Правила находятся в разделе **Система → Рост**: бонус за регистрацию, ежедневная отметка, награда за приглашение, окно привязки. См. [Кабинет партнёра](/docs/partner).

Акции: `/campaign`, настраиваются в разделе **Акции** админ-панели.
