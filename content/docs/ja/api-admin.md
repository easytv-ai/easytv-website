---
title: 管理 API 一覧
description: 管理コンソール向けの /admin/* 。role ≥ 10 が必要で、システム設定の変更、返金、クレジット調整には role ≥ 100 が必要です。
---

呼び出し元は [easytv-manage](https://github.com/easytv-ai/easytv-manage) です。認証は [ユーザー側](/docs/api-auth-login) と同じで、これに管理者ロールが加わります。

次の操作にはスーパー管理者（`role ≥ 100`、RootAuth）が必要です：システム設定、ユーザーの退会、再紐づけ、割り当ての調整、出金の支払い、注文の返金 / 手動での支払い済み処理、クレジット調整、会員プラン / クレジットパック / プロモーション / モデル価格の追加・変更・削除。通常の管理者がこれらを呼び出すと `权限不足` が返ります。

分割した詳細ページは左側にあります：ユーザー、審査、価格設定とゲートウェイ。
