---
title: 生成タスク
description: 作成、ポーリング、キャンセル、リトライ。クレジットは先に事前引き落としされてから精算され、モデルは model_price の有効な一覧にある必要があります。
---

[認証](/docs/api-auth) が必要です。キャンバスの Inspector の「生成」と、チャット欄のテキストタスクはどちらもこのグループを使います。モデル一覧は匿名で取得できます。[モデル](/docs/api-models) を参照してください。

状態遷移：`pending` → `running` → `succeeded` / `failed` / `cancelled`。

- クレジットは `model_price` に基づいて **先に事前引き落とし**（`freeze`）され、成功時に `settle`、失敗 / キャンセル時に返金されます（`unfreeze`、有効期間 365 日）。
- `params.count` は 1 のみ指定できます。
- `model` が有効な一覧にない場合：`模型暂未接入` を返し、保存されません。
- 残高が足りない場合：`积分不足，还需 N 积分`。
- 生成は OpenAI 互換ゲートウェイのみを経由し、ベンダーには直接接続しません。
