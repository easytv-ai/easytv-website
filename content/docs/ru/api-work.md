title: Работы
description: Публикация из ассета, лайки, комментарии. Публичная лента — отдельная анонимная группа.
---

Для CRUD вошедшего пользователя нужна [авторизация](/docs/api-auth). Публичная лента описана в разделе [Публичный API](/docs/api-public).

`status`: 0 — черновик / 1 — опубликовано / 2 — снято с публикации / -1 — отклонено. `review_status`: 0 — на рассмотрении / 1 — одобрено / 2 — отклонено. Публикация не блокируется; модерация проводится постфактум. Чтобы открыть процесс создания, нужен `canvas_id`.
