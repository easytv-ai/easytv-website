キャンバスはスタジオの中核で、パスは `/canvas` です。`?id=` で既存のキャンバスを開き、`?project_id=` でプロジェクトから新規作成します。バックエンドは `graph` を JSON としてそのまま保存し、**ノードの意味は解析しません**。上限は **1 枚あたり 2 MB** です。

![フリーキャンバスのノードと接続線](/images/docs/canvas.png)

## ノードの種類

| kind | 役割 |
| --- | --- |
| `text` | 脚本、プロンプト、画像からの逆算記述。画像を理解できるテキストモデルに、参考画像を最大 4 枚まで渡せます |
| `image` | テキストから画像 / 画像から画像。キャラクターやスタイルをロックできます |
| `video` | テキストから動画、最初と最後のフレーム、参考動画、トーキングヘッド（`videoMode=talking`） |
| `audio` | TTS、BGM、セリフ |
| `storyboard` | 絵コンテグループ：複数の画像をグリッドに並べます |
| `director` | [3D ディレクターステージ](/docs/director) のシーン。同じキャンバスに書き戻されます |
| `panorama` | パノラマ画像 |

空のキャンバスにはスタートカードがあります：ストーリー脚本、キャラクター三面図、オムニリファレンス動画、トーキングヘッド、BGM。[スキル](/docs/community) からテンプレート一式を配置することもできます。

## 実行の流れ

1. 左側または空白部分からノードを追加し、プロンプトを入力してモデルを選びます
2. 上流のノードを下流にドラッグしてつなぎます：画像は動画の最初のフレーム / 参考として、テキストは画像のプロンプトとして使われます
3. ノードの実行ボタンを押します。フロントエンドは `POST /user/task` を呼び、そのあと `GET /user/task/:id` をポーリングします
4. 成功すると生成物は `asset` に書き込まれ、ノードの `content` が再生可能な URL に置き換わります

価格が設定されていないモデルは「模型未定价」とすぐにエラーになり、タスクは作成されません。クレジットは [課金](/docs/billing) のとおり先に事前引き落としされ、失敗またはキャンセル時に返金されます。

動画のパラメータはそのままゲートウェイに渡されます：`ratio` / `resolution` / `duration` / `generate_audio` / `seed` / `negative_prompt`。素材のロール：`first_frame`、`last_frame`、`reference`、`reference_video`、`reference_audio`。

## バージョンと共有

- 自動保存はおよそ 10 分ごとに 1 件にまとめられます。Ctrl+S / 保存ボタンは `snapshot: true` を付けて個別に 1 件記録します
- キャンバス 1 枚につき最大 50 バージョン。履歴からロールバックできます（ロールバック前に現在の稿をもう一度バックアップします）
- `PUT` では現在の `version` を必ず送ります。送らないと「画布已在其他地方修改，请刷新」が返ります
- 共有：`GET/PUT /user/canvas/:id/share`。公開ページは `/share/<token>`（旧 `/s/<token>` は 301 でリダイレクト）。匿名ユーザーは機微な情報を除いた graph を閲覧でき、ログインユーザーは「自分のプロジェクトとしてコピー」できます

## メディアツール

キャンバスのツールバーにあるトリミング、フレーム抽出、無音カット、音声と映像の分離などは [メディアツール](/docs/media) を使います。ローカルの ffmpeg アクションは無料で、超解像、字幕除去、切り抜きなどはモデルの能力タグに応じて課金されます。

ブラウザ上でも FFmpeg.wasm でトリミング / 分割 / 結合ができ、サーバーを経由しません。オブジェクトストレージに CORS が設定されていない場合はスタジオのメディアプロキシを使い、バケットのドメインを `NUXT_PUBLIC_MEDIA_HOSTS` に追加します。
