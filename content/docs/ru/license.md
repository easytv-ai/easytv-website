Репозитории продукта распространяются по двойной лицензии **AGPL-3.0 + коммерческая**:

| Репозиторий | Лицензия |
| --- | --- |
| easytv-api / web / manage / partner | AGPL-3.0 плюс шаблон коммерческой лицензии |
| easytv-website | Только AGPL-3.0 (сайт проекта, не продаётся) |

## Когда достаточно AGPL

Изучайте, изменяйте и разворачивайте у себя, соблюдая AGPL (публикуйте соответствующий исходный код, если предлагаете изменённую версию как сетевой сервис). **AGPL разрешает коммерческое использование**; это копилефт для сетевого использования.

## Когда нужна коммерческая лицензия

Продукт с закрытым кодом либо размещаемая / white-label изменённая версия без этих обязательств по исходному коду. `COMMERCIAL-LICENSE.md` в каждом репозитории продукта — это шаблон; он вступает в силу после подписания заказа (Order).

Напишите на [leida@easyapi.com](mailto:leida@easyapi.com), указав в теме `[LICENSE] easytv-api` (или нужный вам репозиторий).

## Сторонние компоненты

- Режиссёрская сцена — порт [open-director](https://github.com/x1n9/open-director) (MIT)
- Структура пользователей / платежей / объектного хранилища в API следует сторонним открытым проектам; их названия и лицензии перечислены в файле NOTICE репозитория `easytv-api`. **Коммерческая лицензия не перелицензирует эти части**
- Зависимости npm / Go сохраняют собственные лицензии
